## Next separator — E0033

The smallest remaining composition question is whether shared *tails* already carry usable projection evidence.

Different top-level raw environments can share parent suffixes. Each `Env::Cons`/`Env::Framed` already contains a one-entry `(mask, projected-result)` prune memo. E0033 therefore measures, without changing semantics, whether a cold projection walking a Cons node encounters a parent whose cached prune entry already matches the remaining tail mask.

If this opportunity is frequent, the next intervention is not a new ontology: compose existing parent-level projection knowledge before reconstructing the suffix (R7 + R8).

If it is rare, reject tail-reuse composition and move to a quotient-level fingerprint/index experiment (R3/R8).

No optimization is admitted by E0033; it is diagnostic only.
