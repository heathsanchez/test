# V30 — developmental runtime integration

## Frozen question
Can one generic verified-transition runtime, without experiment-specific controller handoffs, take a natural SAIR commitment-defect cell through probe-language development, verified observation, quotient refinement, recomputed common lawful continuation, a first-class successor state, and a fresh residual?

## Frozen theory
The runtime kernel uses one universal intervention object. Probe and constructive steps differ only by typed obligation predicates. Commitment means existence of a common lawful next transition, not terminal solver success.

## Natural corpus
Official public SAIR Stage-2 development distributions: `normal`, `hard1`, `hard2`. Public TRUE/FALSE answers are present in the source corpus but MUST NOT enter routing, incidence, synthesis, state update, or evidentiary cell selection.

## Probe boundary
Old epistemic language: exact V28 order-2 probe programs. Candidate extension carrier: the frozen V28 finite program carrier. V30 does not claim probe-grammar invention.

## Constructive carrier
Two explicit continuation types are supplied by the SAIR adapter:
- `ACCEPT_COUNTERMODEL_WITNESS`: terminal only when the exact synthesized model-existence probe yields a verified witness;
- `ADVANCE_PROOF_SEARCH_FRONTIER`: nonterminal when exact absence of an order-3 countermodel certifies advancement to a successor proof-search state.

The second action exists to test the central correction that lawful continuation is not terminal success.

## No manual handoff
The experiment may instantiate the domain, initial state, and synthesis registry. It may not call probe synthesis directly. The generic runtime must first route `DEVELOP_PROBES`, invoke the registered synthesizer, then reroute.

## Gates
1. generic router selects `DEVELOP_PROBES` before synthesis;
2. synthesis is invoked only through `SynthesisRegistry` from the runtime engine;
3. synthesized probe is absent from the old language;
4. router selects `PROBE` only after extension;
5. version-space/quotient update follows a lawful verified probe transition only;
6. removing the synthesized epistemic extension restores the original obstruction;
7. post-probe continuation is recomputed from common lawful incidence, not predetermined;
8. at least one natural branch executes a lawful nonterminal continuation;
9. successor state differs structurally in fields licensed by the transition;
10. a fresh route/residual is computed from that successor;
11. ablating the first epistemic transition leaves the second continuation unlicensed on the original mixed cell;
12. all required typed obligations are certificate-backed by the adapter;
13. no protected answer is used by routing/synthesis/state update;
14. every order-3 SAT witness used by the inherited V28 carrier is independently rechecked.

## Claim boundary
A pass establishes only that previously separate developmental modules can operate causally as one generic finite runtime on a natural SAIR cell. It does not establish unrestricted probe/action grammar invention, full SAIR solving, clean cross-domain transfer, or long-horizon autonomous development.
