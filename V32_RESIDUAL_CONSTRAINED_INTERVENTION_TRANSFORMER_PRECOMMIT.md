# V32 — Residual-Constrained Intervention Transformer

## Frozen scientific question

Can the canonical developmental runtime respond to a natural successor epistemic obstruction by synthesizing a **new probe transformer from raw AST manipulation affordances**, without being given the semantic operator family `NUMERIC_LITERAL_SHIFT`, and then retain/reuse the verified transformer as a first-class developmental object?

This is the next rung after V31. The V30 router/commitment calculus is frozen. V31 showed that a supplied operator-induction mechanism can learn `NUMERIC_LITERAL_SHIFT(+1)` from a verified order-2 → order-3 probe relation and later reuse it. V32 removes the semantic operator class.

## Claim boundary

The experiment may claim only bounded residual-constrained invention of a reusable intervention transformer over a supplied finite raw AST-edit carrier. It does **not** claim unrestricted grammar invention, arbitrary meta-language invention, broad SAIR solving, or general self-improvement.

## Inputs withheld

The transformer synthesizer must not receive:

- `NUMERIC_LITERAL_SHIFT` or any equivalent semantic operator name;
- `SUCC`, `increment`, `decrement`, or named arithmetic-edit operators;
- protected SAIR TRUE/FALSE labels for routing, synthesis, retention, or state update;
- a predetermined order-4 probe;
- a handoff from experiment code telling it which AST field must change.

## Supplied raw affordances

The finite transformer language may manipulate probe ASTs only through generic structural operations:

1. select a path to an atom;
2. read an integer literal;
3. replace an integer literal by another literal drawn from a bounded literal carrier;
4. copy unchanged subtrees;
5. compare source/candidate tree shape outside the edited atom;
6. compose one structural edit with identity/copy.

No semantic meaning is attached to an edited literal.

## Required chain

The evidentiary trace must be generated through the canonical runtime:

1. reproduce the V30/V31 initial epistemic development and first nonterminal successor;
2. certify that the pre-transformer probe carrier is insufficient for the successor residual;
3. expose a residual constraint `K_meta` over an unknown transformer, stated only in verifier/structural terms;
4. exhaustively enumerate the declared finite raw AST transformer carrier;
5. choose a minimum-cost transformer satisfying `K_meta`;
6. apply it to an installed probe to produce a previously absent probe program;
7. execute and independently verify that probe;
8. recompute commitment incidence from scratch and obtain a common lawful continuation;
9. retain the transformer in explicit developmental state;
10. require later reuse on another compatible successor residual where the old probe carrier alone is insufficient.

## K_meta constraints

A candidate transformer `f` is admissible only if all declared obligations hold:

- `NON_IDENTITY`: `f(p) != p` for the witness source probe;
- `SHAPE_PRESERVED_EXCEPT_EDIT`: tree constructor/argument structure is unchanged outside selected raw literal positions;
- `VERIFIED_DECISION_EFFECT`: the produced probe strictly reduces the current commitment defect or makes the current cell commitment-coherent;
- `TRANSFER`: the same transformer, frozen after induction, produces a verifier-valid useful probe on a second compatible source probe / successor residual;
- `MINIMALITY`: no lower-cost transformer in the frozen carrier satisfies the preceding obligations.

These constraints may not encode the intended numeric delta or target order.

## Falsification

The umbrella gate is false if any gate above fails. In particular:

- If the old carrier already resolves the residual, no transformer invention is licensed.
- If more than one minimal transformer survives with behaviorally distinct verified effects, the experiment reports underdetermination rather than choosing by semantic convenience.
- If the learned transformer is useful only on its induction source and does not transfer to the frozen second application, retention is not evidentiary.
- If removing the transformer does not restore the later obstruction, causal developmental reuse is not established.

A pass supports only the following bounded claim:

> A natural verifier-induced residual can constrain exhaustive search over generic raw intervention transformations strongly enough to construct, verify, type-after-the-fact, retain, and later reuse a new probe transformer that was not supplied as a semantic operator.
