# Procedure-repair experiment

The frozen protocol and implementation contract precede the executable qualification. The experiment will report the original checker failure, generic procedure construction, exact certificate replay, independently checked soundness, held-out transfer and matched controls. This is an isolated successor to certificate-genesis v1. No earlier successful experiment is changed.

The intended result is a bounded demonstration that a verified failure can lead to a change in proof machinery. A green CI status alone is not evidence of that scientific result: the generated certificate, checker soundness and actual residual/control outcomes must also be inspected. No result is claimed by this README.
