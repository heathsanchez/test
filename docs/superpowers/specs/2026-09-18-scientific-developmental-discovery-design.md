# Scientific Developmental Discovery V1 — Design

## Question
Can solving earlier mechanism-identification problems leave behind a domain-independent experimental-design capability that causally reduces the interventions required to identify untouched later mechanisms?

## Domain
Use exact finite mechanism families with different surface vocabularies and latent structures across source and target phases. Each mechanism exposes permitted experiments and deterministic or explicitly enumerated noisy consequences. Learners see only experiment descriptions and observations, never hidden mechanism labels.

## Retained capability
The transferable object is an experimental-development procedure: maintain the surviving behavioural quotient, identify unresolved consequence classes, choose an allowed experiment that maximizes separation of those classes per frozen intervention cost, update the quotient from observed consequence, and stop with a unique mechanism-equivalence class or explicit UNKNOWN. Retained state contains no target mechanism identity or target-specific answer.

## Prospective split
Source mechanism families are solved first and the developmental procedure is serialized. Target families, vocabularies, and hidden instances are generated from a sealed seed only after the procedure, scorer, and controls are frozen. Target families must not be renamings of source truth tables.

## Arms
COLD searches a frozen family of experiment-selection procedures. WARM receives only the retained developmental procedure. RESTART reloads only that procedure. SHAM receives a matched but non-separating/irrelevant procedure. ABLATION removes the active consequence-separation dependency while preserving generic search resources.

## Primary gate
All arms must identify the correct target behavioural class or return UNKNOWN only where the frozen experiment set is genuinely non-identifying. WARM developmental cost and paid interventions must beat COLD, SHAM, and ABLATION on the prospective target suite; RESTART must reproduce WARM; exact ablation must restore the cold frontier. Evidence includes the full consequence ledger and independent replay.

## Interpretation boundary
A pass establishes finite causal transfer of experimental-design capability across distinct exact mechanism families. It does not establish laboratory scientific discovery, biological validity, or noisy real-world experimental performance.
