# Collatz Crystal Future-Quotient Closure Design

**Status:** Approved architecture; implementation target. Global Collatz remains UNKNOWN until the universal certificate boundary is discharged.

## Objective
Compile the current canonical Collatz residual into the smallest source↔endpoint protected-future quotient that preserves genuine exits and lawful continuation. Refine only with independently earned separators. Either emit an independently checkable decreasing-rank certificate for an empty residual kernel, or emit the exact recurrent quotient cell/cycle that blocks closure.

## Consequential state
A compiled residual node contains only:
1. exact affine/source↔endpoint semantic identity needed to replay lawful continuation;
2. exit flags for descent, lower merge, or terminal reach;
3. an ordered separator signature drawn from already-earned exact coordinates only when a witnessed protected-future difference requires it.

Presentation coordinates (raw depth, rung label, Q3 chart, syntax/history, coefficient ceiling) are not identity by default.

## Refinement loop
1. Normalize exact residual occurrences into the current consequential signature.
2. Build exact observed successor relation and genuine exit set.
3. Compute the coarsest stable protected-future quotient.
4. Compute its greatest no-exit post-fixed kernel.
5. If empty, topologically compile a natural rank and emit a Lean finite certificate.
6. If nonempty, inspect each surviving SCC. Search the existing separator bank for the cheapest exact coordinate that splits states with different protected successor/exit futures.
7. Admit only a witnessed separator, recompile from scratch, and repeat.
8. If no earned separator splits a surviving recurrent cell, emit that cell and its exact witnesses as UNKNOWN. Never invent a rank or silently use occurrence/depth identity.

## Universal closure boundary
A finite/observed quotient is not a Collatz proof. Promotion to global closure additionally requires independently checked Collatz-specific normalization/progress:
- every hypothetical minimal bad source maps to the normalized residual representation;
- genuine exits are sound for that source;
- every no-exit normalized state has every lawful residual successor represented by the certified quotient/presentation;
- the generated rank decreases on all such residual transitions, not merely sampled transitions.

The compiler therefore distinguishes `BOUNDED_EMPTY_KERNEL` from `UNIVERSAL_RANK_CERTIFIED`. Only the latter may feed the final no-bad theorem.

## Failure semantics
- A recurrent coarse cell plus a successful separator is representation refinement, not evidence for a Collatz cycle.
- A stable recurrent cell after all currently earned separators is an exact named obstruction and remains UNKNOWN.
- Any missing normalization/progress proof keeps global status UNKNOWN even if every bounded corpus closes.

Existing authorities are referenced by exact lineage rather than recomputed unless the new certificate depends on them.
