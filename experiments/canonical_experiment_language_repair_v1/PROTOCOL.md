# Canonical Experiment-Language Repair V1

The parent experiment-language genesis result is frozen. This qualification
exhausts all 16 Boolean denotations on its four-history carrier.

A repair is any denotation separating the two frozen policy consequences.
Candidates are quotiented by induced history partition, making the comparison
invariant under output complementation. Repairs are ordered by observational
partition refinement, independently of circuit depth or enumeration order.

The run must terminate as exactly one of CANONICAL_REPAIR,
MULTIPLE_MINIMAL_REPAIRS, or NO_REPAIR_IN_META_SUBSTRATE. No outcome is
preselected and the first valid run is immutable.
