# Consequence-Earned Relation V37 — Frozen Protocol

## Question

Can the circular adjacency and named frame lattice still supplied by V35 be removed?

V37 begins from a complete finite table of binary configurations on anonymous sites and externally verified consequence labels. The scientific core is not given a graph, cycle, path, neighborhood, rotation, reflection, orientation, anchor, frame class, or event window.

The first stage computes the largest permutation symmetry of the site set that is actually compatible with consequence. The second stage asks whether that earned symmetry can be realized by a minimal anonymous simple undirected binary relation.

## Frozen substrate

Each world supplies only:

- a fixed finite number of anonymous binary sites;
- the complete table of all binary configurations on those sites;
- one externally verified opaque consequence label per configuration.

The core may use generic finite permutation and binary-relation machinery. This is a substantial prior.

Not supplied:

- adjacency or neighborhood;
- a cycle/path/grid/tree class;
- start, direction, orientation, anchor, or frame;
- a named symmetry group;
- candidate UNFRAMED/ORIENTED/ANCHORED/FRAMED states;
- canonical cycle representatives;
- semantic event windows;
- the hidden relation used to generate any challenge.

## Consequence-preserving symmetry

For a world with site set X and consequence C, the core retains exactly the permutations p of X satisfying

    C(x) = C(p.x)

for every authoritative configuration x.

This gives the exact automorphism group of the observed consequence table inside the supplied permutation substrate.

No subgroup family is enumerated in advance.

## Relational realization

Given the earned consequence symmetry H, the core searches the complete class of simple undirected binary relations on the finite site set.

A candidate relation R is admissible only when

    Aut(R) = H

exactly.

Among admissible relations, retain every relation with the minimum number of edges. If several incomparable relations tie, preserve the entire frontier. Do not select one by a hidden lexical preference.

Thus relation genesis is claimed only inside this declared finite binary-relation class.

## Raw support

Separately from any global canonicalization, the core can compute the smallest fixed raw site support S for which equal values on S always imply equal verified consequence.

This is used to distinguish true fixed raw support from a short prefix of a globally canonicalized representation.

## Post-freeze challenge family

After this scientific core is frozen, hidden worlds may contain:

- maximally symmetric constant consequence;
- a hidden six-site relation whose exact consequence symmetry has a unique sparsest relational realization;
- a hidden relation whose symmetry admits several incomparable sparsest realizations;
- opaque relabellings of consequence values;
- consequences whose symmetry successively shrinks without any named frame lattice;
- globally canonicalized consequences with deceptively short canonical codes but full raw support;
- genuinely local consequences with two- and three-site raw support.

## Frozen gates

R1. Frozen scientific core remains byte-identical after challenge commit.
R2. Constant consequence retains the full permutation group and the empty relation.
R3. A hidden six-site neighborhood world earns a 12-element consequence symmetry.
R4. Its unique sparsest exact relational realization has six edges and equals the hidden relation.
R5. Opaque consequence-label relabelling preserves earned symmetry and relational frontier.
R6. A second hidden relation earns a two-element consequence symmetry.
R7. That symmetry admits multiple incomparable sparsest exact relational realizations and the hidden relation remains on the frontier.
R8. No single relation is silently chosen when the minimal frontier is non-canonical.
R9. Without a supplied frame lattice, four post-freeze consequence families independently earn symmetry groups of sizes 12, 6, 2, and 1.
R10. The 12-element group from R9 equals the symmetry earned by the hidden neighborhood world.
R11. A V35-style one-symbol canonical consequence requires all six raw sites when raw support is measured directly.
R12. A genuinely local two-site consequence has minimum raw support two.
R13. Increasing the local consequence from two to three sites increases minimum raw support from two to three without global canonicalization.
R14. Incomplete authority remains UNKNOWN_AUTHORITY.
R15. Verifier ablation authorizes neither symmetry nor relation.
R16. The frozen kernel contains no hidden topology or V35 frame names.
R17. Every retained relation has automorphism group exactly equal to the earned consequence symmetry.
R18. The relation search preserves every edge-minimal exact realization.

## Claim boundary

A pass would establish only:

> within a complete finite binary site table, generic finite permutations, a complete simple-undirected-binary-relation hypothesis class, and external verified consequence, adjacency need not be supplied as a fact. Consequence can first earn a permutation symmetry and then constrain a minimal relational realization; when that realization is not unique, the lawful frontier remains plural.

It would also establish that V35's canonical event-window length must not automatically be interpreted as physical/local support.

V37 still supplies:

- discrete binary sample values;
- discrete site slots;
- simultaneous configuration boundaries;
- the full finite permutation substrate;
- the simple undirected binary relation language;
- complete finite authority;
- external verification.

The next frontier is to weaken those remaining priors and combine earned spatial relation with consequence-earned temporal segmentation.
