# Controller Replay V1

Question: can an explicit process controller choose the historically useful research mode from pre-result state, rather than simply continuing local search?

This is a first retrospective/prequential smoke test, not independent evidence. Cases are frozen snapshots from the recent RGRS Lean-kernel sequence and labels describe the next mode that the subsequent evidence made useful.

Modes:
- EXPLOIT: continue current-frame search.
- INSPECT_CLOSURE: inspect whether the proposed missing object/mechanism already exists.
- MAP: gather cheap cartography because the residual is not sharp enough for a deciding test.
- REFRAME: change explanatory frame after repeated/conditional residuals.
- DISCRIMINATE: run a frozen separator when rival explanations and a deciding test are ready.

The comparator is deliberately strong in one sense and weak in another: it can run a ready separator, but otherwise stays local. V1 therefore tests only whether explicit altitude-switch triggers can recover the observed mode changes. It does NOT establish causal superiority, information-gain superiority, generalization, or autonomous research ability.

Pass condition: controller mode accuracy exceeds local-only baseline and is perfect on the five frozen smoke cases.

Next required test: freeze the rule before labeling a larger set of historical episodes from other programmes (SAIR, Triskelion, MathGraph), score blind, then prospectively let controller-vs-local choose experiments under matched budgets. The prospective comparison should measure information gained per unit resource and downstream residual reduction, not merely agreement with historical choices.
