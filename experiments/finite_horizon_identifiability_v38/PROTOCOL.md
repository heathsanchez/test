# Finite-Horizon Identifiability V38 — Frozen Protocol

## Question

How far can consequence-earned ontology be pushed before finite evidence becomes mathematically insufficient?

V38 tests the boundary directly. The kernel receives complete finite consequence tables over anonymous finite token sequences. It is asked to distinguish bounded equivalence from global equivalence.

The key issue is whether any finite observation horizon, by itself, can justify the claim that two presents will remain consequence-equivalent under every longer continuation.

## Frozen substrate

Each world supplies:

- an anonymous finite alphabet size;
- a complete consequence table for every token sequence through a declared finite depth;
- externally verified consequence labels.

Not supplied:

- a semantic state machine;
- a maximum true distinguishing horizon;
- a theorem that no later separator exists;
- a global completeness certificate.

## Constitutional rule

For complete tables through depth d:

- if a separating sequence is already observed, non-equivalence is VERIFIED;
- if the tables agree through d, equivalence is VERIFIED only through d;
- absent an external completeness certificate, global equivalence remains UNKNOWN_BEYOND_FINITE_HORIZON.

The kernel therefore refuses to convert finite non-separation into universal equivalence.

## Post-freeze challenge

After the core is frozen, the challenge may construct pairs of worlds that:

1. agree on every sequence through depth d;
2. have exactly the same finite observation signature;
3. diverge at depth d+1.

It may also include pairs that never diverge within the supplied finite scope.

The kernel does not know which case it is in from the depth-d table alone.

## Frozen gates

H1. Frozen scientific core remains byte-identical after challenge commit.
H2. Every challenge prefix table is complete over its declared finite horizon.
H3. For each tested d, the two challenge worlds are observationally identical through d.
H4. For each such identical finite prefix, the global verdict remains UNKNOWN_BEYOND_FINITE_HORIZON.
H5. One additional authorized consequence layer exposes an explicit separator at d+1.
H6. The separator causes VERIFIED_NOT_EQUIVALENT rather than a representational or search guess.
H7. Bounded equivalence through d is still positively verified.
H8. The same pair fails bounded equivalence through d+1.
H9. The underdetermination construction succeeds for every tested d in the frozen challenge range.
H10. A genuinely identical pair also remains globally UNKNOWN without a global completeness certificate.
H11. When the task explicitly declares a finite horizon B as the whole authority domain, equality through B can be VERIFIED_BOUNDED_EQUIVALENCE.
H12. Incomplete finite authority remains UNKNOWN_AUTHORITY.
H13. Verifier ablation authorizes no equivalence or separation claim.
H14. The frozen kernel contains no hidden delayed-separator pattern or challenge depth.
H15. The same finite observation signature admits both a continuation that remains equal and a continuation that later separates.

## Claim boundary

A pass establishes a genuine epistemic stopping point:

> complete finite non-separation does not warrant universal identity unless an additional bound, completeness theorem, or future consequence closes the continuation space.

This is not a limitation of one representation search procedure. The same finite input table can be extended in mutually incompatible ways.

Therefore observation horizon can develop by acquiring more consequence, but no purely finite developmental algorithm can certify that no later distinction exists in an unrestricted continuation space without some additional grounding assumption.

The remaining irreducible issue is no longer another semantic primitive. It is warrant: what authorizes finite evidence to stand for an unbounded claim?
