# Finite Transformation-Monoid Genesis V44 — Frozen Protocol

## Question

Can reversibility itself be removed as a supplied property of interventions?

V44 receives only:

- a finite opaque state set X;
- complete deterministic total transformations X -> X indexed by opaque action tokens;
- verified consequence classes over those actions.

Unlike V43, the scientific kernel does NOT require an action to be bijective.

Every observed action may be reversible, many-to-one, idempotent, eventually collapsing, or coupled with other classes.

The hidden challenge pack is committed only after the scientific core is frozen.

## Generic algebraic substrate

For each verified action class C_i, the kernel closes the observed maps in that class under ordinary composition while adjoining identity.

This produces a finite transformation monoid M_i.

It also closes all observed actions together to obtain M.

No candidate “group”, “reset”, “contraction”, or other algebra type is proposed.

The kernel records algebraic invariants forced by closure:

- monoid order;
- rank spectrum of its maps;
- number of full-rank elements;
- whether every element is full-rank;
- minimum rank;
- number of idempotents;
- number of nonidentity idempotents;
- number of constant maps.

For a finite self-map of X, full rank is equivalent to invertibility. Therefore reversibility is read off after closure rather than assumed by authority validation.

## Derived rank behavior

The kernel reports only three generic rank regimes:

- NO_RANK_LOSS: every generated map has rank |X|;
- PARTIAL_RANK_LOSS: some generated map loses states but no generated map collapses X to one point;
- GLOBAL_COLLAPSE_PRESENT: the generated closure contains a rank-1 map.

These labels summarize measured algebraic invariants; they are not candidate ontologies.

## Interaction between verified action classes

For multiple action classes, the kernel computes:

- whether all class monoids commute pairwise;
- whether pairwise intersections contain identity only;
- the product of class-monoid cardinalities;
- the image of multiplying one element from each class monoid;
- whether that multiplication representation is injective;
- whether it spans the full generated monoid.

This yields an internal direct-monoid criterion without assuming that the state space itself is a Cartesian product.

The kernel also computes weak action components of X by treating every observed transition edge as undirected.

## Global classifications

### DERIVED_DIRECT_MONOID_COMPLEMENTARITY

Returned only if:

- class monoids commute pairwise;
- pairwise intersections are identity only;
- multiplication coordinates are unique;
- their multiplication image equals the full generated monoid;
- the observed action graph is weakly connected.

The class monoids may be reversible, irreversible, or mixed.

### UNDERRESOLVED_MULTIPLE_ACTION_COMPONENTS

The same internal direct-monoid conditions hold, but current actions leave multiple disconnected state components.

### COUPLED_TRANSFORMATION_MONOID

Returned when the class actions do not satisfy the direct-complementarity algebra, including noncommutation or nonunique class multiplication.

### UNDECOMPOSED_SINGLE_CLASS

If consequence authorizes only one action class, V44 does not split it into components even if its generated monoid has rich internal structure.

## Post-freeze challenge family

After freeze the harness will instantiate:

- a reversible one-class control generated by a rich hidden system;
- an irreversible one-class contraction chain whose generated ranks descend 8 -> 4 -> 2 -> 1;
- a two-class reversible system from a three-degree hidden generator, leaving one unobserved degree and therefore two weak state components;
- the corresponding three-class reversible system, yielding direct complementarity;
- a three-class system made only of independent irreversible idempotent resets;
- an independent two-class mixed system where one class is fully reversible and the other class generates both reversible maps and rank-loss maps;
- a coupled two-class system with one reversible map and one irreversible reset acting on the same hidden degree, chosen so monoid cardinalities alone tempt a false decomposition;
- independent opaque-state relabellings and consequence-label relabellings.

The hidden harness may use convenient coordinates internally. The frozen kernel never receives them.

## Frozen gates

M1. Frozen scientific core remains byte-identical.

M2. Reversible one-class control remains UNDECOMPOSED_SINGLE_CLASS and its class/full monoid has NO_RANK_LOSS with all elements units.

M3. Irreversible one-class chain remains UNDECOMPOSED_SINGLE_CLASS but its generated closure has rank spectrum {1,2,4,8}, minimum rank 1, a nonidentity idempotent, and GLOBAL_COLLAPSE_PRESENT.

M4. Two reversible action classes from the hidden three-degree system generate two order-2 all-unit class monoids and an order-4 all-unit full monoid, but leave two weak state components and therefore UNDERRESOLVED_MULTIPLE_ACTION_COMPONENTS.

M5. Adding the third reversible class yields three order-2 all-unit class monoids, an order-8 all-unit full monoid, one weak state component, and DERIVED_DIRECT_MONOID_COMPLEMENTARITY.

M6. Three independent irreversible reset classes each generate an order-2 monoid with exactly one unit, minimum rank 4, and one nonidentity idempotent; together they generate an order-8 direct monoid with one weak state component.

M7. The independent mixed two-class world yields one all-unit order-2 class and one order-8 class containing four units and rank-loss elements; the full generated monoid has order 16 and is still DERIVED_DIRECT_MONOID_COMPLEMENTARITY.

M8. The mixed class in M7 has rank spectrum {2,8}, minimum rank 2, nonidentity idempotents, and PARTIAL_RANK_LOSS.

M9. The coupled flip/reset control has two order-2 class monoids with identity-only intersection and cardinality product equal to the full monoid order, yet noncommutation prevents direct complementarity and forces COUPLED_TRANSFORMATION_MONOID.

M10. Opaque-state relabelling preserves all algebraic profiles, weak-component counts, and classifications.

M11. Consequence-label relabelling preserves all algebraic profiles and classifications.

M12. Removing the third reversible class from the full reversible generator restores the two-class underresolved algebra.

M13. A one-class bound preserves both one-class controls but rejects every multi-class world before monoid interaction analysis.

M14. Incomplete authority remains UNKNOWN_AUTHORITY and verifier ablation performs zero algebraic construction.

M15. The frozen authority check contains no bijectivity/permutation requirement; irreversible hidden worlds are accepted without a special path.

M16. Named hidden challenge families, graph/site/channel vocabulary, and hidden coordinate maps are absent from the frozen executable kernel.

## Claim boundary

A pass would not establish the correct algebraic language for arbitrary natural dynamics.

V44 still supplies:

- a finite opaque state set;
- complete deterministic total action tables;
- verified consequence classes;
- composition and identity as the generic finite-transformation algebra;
- weak connectivity as a residual-resolution diagnostic.

What a pass can establish is narrower:

> reversibility need not be supplied. It can be derived from the rank structure of the generated transformation closure, while independent reversible and irreversible action classes can be distinguished from genuinely coupled dynamics by their composition law.

If V44 passes, the remaining handhold is determinism and totality: every intervention is still represented as one total function X -> X. The next frontier is to admit partial, stochastic, or nondeterministic transition relations and ask which law—function, relation, probability kernel, order, or obstruction—is actually warranted by consequence.
