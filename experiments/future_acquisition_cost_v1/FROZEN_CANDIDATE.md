# Future Acquisition Cost V1 — Frozen Candidate

**Status:** FROZEN BEFORE TEST  
**Date:** 2026-09-14

## Candidate

Immediate least commitment is not, by itself, a universal developmental selector.

If two lawful presents preserve all current protected consequence, a present that retains extra currently-redundant structure can still be developmentally preferable when the authorized horizon includes future acquisition cost.

The developmental preorder must therefore be indexed by the warranted horizon/scope:

```math
\preceq_{E,H}.
```

## Frozen sequential family

At time 0 two lawful presents are available:

- PRUNE: immediate carrying cost 0; loses seed/capability.
- RETAIN: immediate carrying cost c>0; preserves seed/capability.

If a future task requiring the seed arrives:
- PRUNE pays reacquisition cost R;
- RETAIN pays 0 reacquisition.

If no such task arrives, RETAIN paid unnecessary carrying cost.

## Predictions

- current-only horizon chooses PRUNE;
- future-aware horizon chooses RETAIN exactly when warranted expected/known reacquisition cost exceeds carrying cost;
- if future demand is absent or sufficiently unlikely, PRUNE remains correct;
- there is no unconditional “always retain” or “always prune” law.

## Falsifier

V1 fails if current-only minimality is always globally optimal in the frozen family, or if one fixed retention policy is optimal across all future-demand regimes.
