The frozen continuation-major traversal did not reduce aggregate fully charged verifier cost on the new immutable-token-trace carrier once target and operation order were exhaustively counterbalanced. It exactly tied cold: 122,976 versus 122,976 calls.

## Consequence for the prior C4 result

The prior C4 result remains a bounded causal fact about that run, but this prospective counterbalanced test does not support interpreting its 266-to-161 reduction as transfer of a generic quotient construction. The implemented reusable object was continuation-major traversal. On the new carrier, counterbalancing exposed it as enumeration order rather than learned consequence-dependent selection.

## Most consequential residual

The controller lacks a learned, verifier-grounded rule that maps continuation profiles to candidate preference independently of incidental enumeration order. A genuine test of the quotient kernel now requires profile equivalence classes plus an externally justified choice rule; merely traversing continuations first is insufficient.
