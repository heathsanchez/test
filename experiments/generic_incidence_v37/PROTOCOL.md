# Generic Incidence Genesis V37 — Frozen Protocol

## Question

Can the graph ontology itself be removed?

V37 does not give the scientific kernel a notion of edge, direction, undirectedness, graph, hyperedge, or named relation type.

It receives only:

- a finite set of stable anonymous sites;
- finite site values;
- complete finite consequence authority in the primary tests;
- a generic incidence language.

A single incidence unit is generated as follows:

1. choose an arity k;
2. choose an ordered k-word of distinct anonymous sites;
3. choose any subgroup H of the coordinate-permutation group S_k;
4. close the word under H.

The incidence unit is only the resulting orbit of anonymous words.

No semantic label is attached to k, H, or the resulting orbit.

A representation is an unordered finite set of incidence units.

## Generic observation

For one encounter and one incidence unit, evaluate every concrete word in the orbit and retain the sorted multiset of value-words.

For a multi-unit structure, retain the sorted multiset of unit signatures.

Site identities and unit ordering are therefore not exported into the consequence quotient.

A candidate is accepted only if this generic incidence signature induces exactly the authoritative consequence partition. Finer-than-authority distinctions are rejected.

## Developmental search order

The frozen structural metric is lexicographic:

    (
        number of incidence units,
        sum of base arities,
        total number of concrete orbit words
    )

There are no tuned coefficients.

Search exhausts every candidate at one metric before moving to the next metric.

The primary bounded language freezes:

- maximum arity = 3;
- maximum incidence units = 2.

These are experimental bounds, not claims of universal adequacy.

## Generic coordinate symmetry

For each arity k <= 3, the kernel generates every subgroup of S_k by exhaustive closure testing.

Thus internal coordinate symmetry is not selected from a named catalogue.

A one-word orbit, two-word orbit, three-word orbit, and full permutation orbit are all generated by the same rule.

The executable kernel contains no branch saying which semantic relation type such an orbit represents.

## Post-freeze challenge family

Only after freeze, the evaluation harness will instantiate several hidden structures spanning:

- different minimum arities;
- different internal coordinate-symmetry subgroups;
- a multi-unit structure;
- independent site relabellings;
- independent consequence-label relabellings.

The scientific kernel is not told the semantic interpretation of these hidden structures.

## Frozen gates

I1. Frozen scientific core remains byte-identical.
I2. One frozen kernel recovers every post-freeze world at the correct minimum structural metric.
I3. Every primary hidden world has exactly one minimum canonical incidence class up to site relabelling.
I4. A zero-unit control retains no incidence.
I5. A minimum arity-1 world is solved before any larger arity is authorized.
I6. Two distinct arity-2 internal symmetry classes are recovered at different minimum orbit sizes without named relation types.
I7. A minimum arity-3 one-word orbit is not replaceable by any arity-1 or arity-2 structure.
I8. A minimum arity-3 three-word coordinate orbit is recovered only after all cheaper arity-3 symmetry structures fail.
I9. A minimum arity-3 full coordinate orbit is recovered only after all smaller coordinate orbits fail.
I10. A two-unit world cannot be represented by any one-unit incidence and is recovered at the correct two-unit metric.
I11. Site relabelling preserves the recovered canonical incidence class.
I12. Consequence-label relabelling preserves the minimum metric and canonical class.
I13. Arity ablation at maximum arity 2 blocks every genuinely arity-3 world.
I14. Coordinate-symmetry ablation blocks worlds whose minimum one-unit representation requires a nontrivial coordinate orbit.
I15. Incomplete authority remains UNKNOWN_AUTHORITY and verifier ablation authorizes no incidence search.
I16. Named semantic relation types and hidden challenge-family names are absent from the frozen executable kernel.

## Claim boundary

A pass would not establish unrestricted relation-language invention.

V37 still supplies:

- persistent anonymous site identity within an encounter;
- the abstract notion of a finite ordered word of sites;
- coordinate permutation and subgroup closure;
- a finite maximum arity;
- a finite maximum number of incidence units;
- a generic incidence-signature semantics;
- lexicographic structural cost;
- external consequence authority.

What a pass can establish is narrower:

> pairwise adjacency need not be the supplied ontology. Within one generic incidence-orbit substrate, verified consequence can select the minimum arity, support, coordinate symmetry, and number of incidence units required to preserve consequence.

Semantic descriptions such as one-place marker, oriented pair, symmetric pair, cyclic three-place relation, or fully symmetric three-place relation are interpretive labels applied only after verified construction.

If V37 passes, the next remaining handhold is the incidence-orbit language itself: the system is still told that organization should be representable as finite words of persistent sites acted on by coordinate permutations.
