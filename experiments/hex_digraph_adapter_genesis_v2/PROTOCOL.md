# Hex Digraph Adapter Genesis V2 — Frozen Protocol

## Question

Can a bounded adapter substrate synthesize, from semantic evidence alone, a least-cost representation that transports finite directed-graph isomorphism into the independently developed verified HexGraphIso capability, while rejecting cheaper inadequate representations and then succeeding on held-out larger obligations?

V1 supplied the successful role-split adapter by hand and qualified it exhaustively. V2 removes that choice. Only a finite adapter grammar is supplied.

## External capability freeze

- capability: `leanprover/hex-graph-iso`
- release: `v0.6.0`
- commit: `f247c0898414ca29c502691e3a8ad0b3ce0b4f6a`
- Lean toolchain: `leanprover/lean4:v4.34.0-rc2`

Hex remains external authority. V2 searches only the transport into Hex's coloured undirected graph language.

## Source semantics

Source objects are loopless directed graphs on a fixed labelled carrier.

Source isomorphism is exact and independent: all vertex permutations are enumerated and the lexicographically least relabelled arc set is the canonical source signature.

## Frozen adapter grammar

A candidate adapter is a tuple:

`(role_count, arc_channel, identity_couplings)`

where:

- `role_count ∈ {1,2,3}`;
- every source vertex is copied once into each anonymous target role;
- `arc_channel = (a,b)` chooses the source-role copy of an arc tail and arc head;
- `identity_couplings` is any subset of unordered pairs of distinct roles;
- for each selected identity coupling `{a,b}`, every source vertex contributes an undirected edge between its role-`a` and role-`b` copies;
- source arc `u -> v` contributes one undirected target edge between `role_a(u)` and `role_b(v)`;
- target roles are ordered Hex colours and cannot be permuted by isomorphism.

All 81 candidates generated by this grammar are declared before qualification.

The role labels have no supplied semantics such as OUT, IN, or ANCHOR.

## Qualification world

Exhaust all 64 loopless directed graphs on 3 vertices and all 4,096 ordered graph pairs.

For every candidate:

1. compute the exact source-isomorphism equivalence relation;
2. compute the exact colour-preserving target-isomorphism equivalence relation by exhaustive independent permutations inside each target role;
3. count every disagreement over the 4,096 ordered source pairs.

A candidate is semantically qualified iff disagreement count is exactly zero.

## Search and selection

Candidates are ranked by the precommitted structural cost:

1. fewer role copies;
2. fewer identity-coupling types;
3. lexicographic `arc_channel`;
4. lexicographic identity-coupling list.

The search is level-complete in the first two cost coordinates. All candidates at a cost level are evaluated before moving to a more expensive level.

The selected adapter is the lexicographically first qualified candidate at the least successful cost level.

No held-out n=4 object participates in qualification or selection.

## Causal controls

- At least one candidate with fewer role copies than the winner must fail.
- Removing either identity coupling from a two-coupling winner must restore semantic disagreement.
- A direction-erasing one-role representation must fail.
- The complete candidate count must equal 81.

## Held-out compilation

Only after selection, a generator reads `results/selected_adapter.json` and emits a Lean file for unseen n=4 obligations:

- one positive directed-isomorphism pair;
- one negative pair that has the same underlying undirected graph;
- one direction-erasing lossy control.

The generated adapter is not hard-coded in the Lean file source before selection. Hex then kernel-checks the generated obligations.

## Precommitted pass

A V2 pass requires:

- complete 81-candidate search;
- a qualified adapter exists;
- no cheaper cost level contains a qualified adapter;
- selected adapter has zero disagreement on all 4,096 qualification pairs;
- both one-coupling ablations fail qualification;
- the one-role direction-erasing control fails qualification;
- generated held-out positive and negative Hex obligations both close correctly;
- the lossy held-out control closes as an isomorphism;
- all evidence and generated source are sealed.

## Claim boundary

A pass earns **bounded exhaustive adapter genesis and held-out verified exaptation inside the declared finite grammar**.

It does not establish:

- autonomous invention of the adapter grammar;
- a theorem of adapter faithfulness for all finite sizes;
- open-ended representation invention;
- broad natural-domain transfer;
- unbounded developmental intelligence.
