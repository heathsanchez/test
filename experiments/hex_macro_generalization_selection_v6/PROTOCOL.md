# Macro Generalization Selection V6

## Frozen question

The prior one-relation experiment supports a successful developmental pattern, but several extrapolations agree perfectly on that prior case. This experiment asks whether a separately frozen two-relation consequence can select which extrapolation should persist.

## Prior evidence

V4 established compositional repair genesis for one directed relation. V5 established successful promotion and downstream Hex verification in a two-relation language.

## Candidate extrapolations

Three candidates are frozen before evaluation.

- Candidate A connects the endpoint roles of every named relation to the new role.
- Candidate B connects only the endpoint roles of the first named relation.
- Candidate C connects only the endpoint roles of the last named relation.

With exactly one named relation, A, B, and C are identical: all connect roles 0 and 1. Thus the prior case cannot distinguish them.

## Future consequence

Evaluate the complete V5 bounded qualification world: two named loopless directed binary relations on three vertices, exactly one arc per relation, 36 objects and 1,296 ordered pairs.

For each candidate, compare exact source isomorphism under one common vertex permutation with exact colour-preserving target isomorphism.

## Pass criteria

All three candidates must match the prior one-relation behavior exactly. Candidates B and C must fail on the future world. Candidate A alone must have zero semantic disagreement and must match the pattern independently checked through Hex in V5.

## Claim boundary

This tests finite selection among supplied extrapolation candidates. It does not establish autonomous generation of the candidate family.
