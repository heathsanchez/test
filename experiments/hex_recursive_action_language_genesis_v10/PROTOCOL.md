# Recursive Action-Language Genesis V10 — Frozen Protocol

## Question

Can the same consequence-governed rule recurse one level upward when the *complete current action language itself* is certified inadequate, rather than merely selecting a new primitive inside that language?

This experiment starts from the sealed V9 contraction authority. It is deliberately finite and synthetic so that completeness can be exhaustive and the constitutional distinction between search failure and expressive inadequacy can be exact.

## Frozen task family

For an ordered family of relation positions of arity m >= 4, the verified target activates exactly the second position.

No semantic name for the required new observation is present in the initial language.

## Initial observation/action language

Observations:
- FIRST
- LAST

Action programs:
- the complete set of all 16 Boolean functions of (FIRST, LAST).

Qualification encounter:
- arity 4.

Growth is forbidden unless all 16 programs are exhausted and none matches the target.

## Certified obstruction

At arity 4, positions 1 and 2 both have observation signature (FIRST=0, LAST=0), but the frozen target assigns them different outputs.

Therefore no Boolean function of the complete current observation language can solve the encounter. This is an extensional obstruction, not a search timeout.

## Frozen higher-order growth constructor

The only permitted recursive growth operation is:

1. take the witnessed old-equivalence class containing the conflict;
2. add one new Boolean observation that refines only that class;
3. at minimum one-bit refinement cost, generate its ordered extrema:
   - left edge of the conflicting class;
   - right edge of the conflicting class;
4. for each refinement, exhaust the complete 256 Boolean functions of (FIRST, LAST, NEW).

The growth constructor is supplied and frozen. The useful new primitive is not supplied.

## Non-canonicity and future consequence

At arity 4, both minimum refinements must admit at least one exact action program.

The independently frozen arity-5 continuation then decides which refinement persists. No tie-breaking by name or designer preference is allowed.

## Promotion and contraction

After future consequence selects a refinement, select the qualifying action program with minimum full-cube dependency support.

Replay arities 4 and 5.

If the selected action depends only on the generated observation, FIRST and LAST are removable developmental scaffolding for this retained capability.

## Held-out transfer

Without redevelopment, replay the retained capability on arities 6 and 7.

Compare one warm program evaluation with the candidate evaluations required by cold redevelopment under the same frozen protocol.

## Constitutional controls

- Ablation: remove the generated observation and confirm the complete old language is again inadequate.
- Sham growth: duplicate FIRST or add a constant-zero bit; exhaust all 256 programs and require failure.
- Incomplete-search control: inspect only a strict prefix of the old program space and require UNKNOWN, not permission to grow.
- Independent verifier: separately reconstruct the complete old and grown program spaces and all decisive claims.
- Lean kernel check: certify the collision obstruction and the selected contraction law.

## Pass condition

Pass only if all gates succeed:
1. complete old program space exhausted;
2. old space has no exact program;
3. an explicit same-observation/different-consequence collision exists;
4. both minimum one-bit refinements solve arity 4;
5. arity 5 selects exactly one refinement;
6. the minimum retained program depends only on the generated bit;
7. protected replay is exact;
8. arities 6 and 7 transfer exactly;
9. ablation and sham controls fail;
10. incomplete search yields UNKNOWN;
11. warm reuse is cheaper than cold redevelopment;
12. independent verifier and Lean kernel check pass.

## Claim boundary

A pass establishes bounded recursive action-language growth under a supplied frozen higher-order refinement constructor.

It does **not** establish invention ex nihilo, an unsupplied lowest-level substrate, open-ended self-development, universal completeness, or designerless subject selection.
