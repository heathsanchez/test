# Korovin V13 — Autonomous Theory Extension From Invented Objects

This protocol is frozen before protected V13 law candidates are generated or inspected.

## Question

After the verified finite mathematical object has been invented, completed, and sealed, can an independent downstream theorist use only that object — without the original transformation oracle — to formulate and decide new mathematical equalities outside the discovery presentation?

## Frozen source worlds

V10 root: `KOROVIN_V10_PUBLIC_COMPLETION_TRANSFER_2026-08-22`.
Exactly residual-bearing indices 4, 5, 11. Expected reachable state counts: 25, 79, 43.

## Sealed OBJECT artifact

For each world construct the already-verified canonical artifact consisting only of:
- alphabet {a,b};
- canonical state IDs and shortest representatives;
- complete certified state x generator transition table;
- final retained V10 equations and certificate provenance.

The V13 theorist receives no primitive 4-point transformation maps and no semantic execution function.

## Protected conjecture universe

Root phrase: `KOROVIN_V13_THEORY_EXTENSION_2026-08-22`.

For each world deterministically generate 2,000 distinct equation candidates `(u,v)` after sealing:
- 1,000 positive candidates: distinct words with identical sealed-object state, neither orientation equal to any retained V10 rule;
- 1,000 negative candidates: words with different sealed-object states;
- word lengths independently drawn in [8,80], beyond the original candidate-side horizon <=5.

The positive pairs are sampled only by sealed-object state equality. The original semantic oracle may not be consulted during candidate generation or V13 decision.

## Decision arms

OBJECT: decide every conjecture by evaluating both words solely through the sealed canonical transition table.

SHAM: identical artifact dimensions and word-processing budget, but state-transition destinations are deterministically randomized from a separately frozen seed.

RAW is not a V13 decision arm because the question is whether mathematics can continue after the original oracle is explicitly removed. RAW is used only by the external scorer after all decisions are frozen.

## External scoring

Only after OBJECT and SHAM decisions are complete, independently evaluate both words with the hidden original transformation semantics. Report false positives and false negatives separately.

## Novel-law subset

For every OBJECT-positive conjecture:
- require that neither orientation is one of the retained V10 equations;
- require both sides length >=8;
- classify as a new derived law relative to the retained presentation.

For each world retain the 20 shortest lexicographically earliest new true laws as a human-readable THEORY_EXTENSION artifact.

## Gates

G0 exactly worlds [4,5,11] and state counts [25,79,43].
G1 6,000 protected conjectures total, balanced 3,000 positive / 3,000 negative.
G2 OBJECT makes zero original-semantic-oracle calls.
G3 OBJECT decision accuracy = 1.0 against post-hoc external scoring.
G4 OBJECT false positives = 0 and false negatives = 0.
G5 every OBJECT-positive pair is absent from the retained V10 rule list in both orientations.
G6 every OBJECT-positive side length >=8.
G7 each world yields at least 20 new true derived laws for the human-readable extension artifact.
G8 SHAM accuracy < 0.75 under the identical query and table-size budget.
G9 all 60 retained extension laws independently verify true under the hidden original semantics post hoc.

## Claim boundary

A pass establishes autonomous theory extension inside these finite transformation worlds: a downstream system can use the invented verified object itself to formulate and correctly decide new mathematical equalities beyond the original discovery grammar, after the original semantic oracle has been removed. This does not establish historical novelty or usefulness to independent human mathematicians.
