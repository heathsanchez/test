# Korovin Usable Theory Formation V5 — Frozen Protocol

## Developmental inheritance

V3 established that an observation-based representation program is causally necessary. V4 established that the distinctions inside that carrier can be synthesized from a low-level Boolean predicate grammar.

V5 asks the next Korovin-facing question: can the recovered object be turned into **compact human-usable mathematics**, rather than merely an opaque state table?

## Question

Can a generic generator discover a small set of verified equations whose contextual closure reconstructs the object's bounded equational theory and continues to do so on longer unseen words?

## Candidate generation and trust boundary

For each opaque world:

1. enumerate all distinct word pairs with each side length <= 4;
2. propose each pair as a candidate equation;
3. an exact external semantic oracle admits only equations whose two sides have identical behavior;
4. the theory learner may only select among admitted equations.

No algebraic object name, known presentation, group axiom, target relation, or expected rule count is supplied.

## Theory selection

Training universe: all words of length <= 7.

Start with no equations. Repeatedly select the true equation that yields the largest additional lawful quotient compression under full contextual closure. Ties prefer lower description length.

Maximum retained rules: 8. Stop when the contextual congruence exactly matches the semantic equivalence classes or no candidate improves it.

## Protected transfer

After freezing the rule set, recompute contextual closure on all words of length <= 9. The learned theory must make zero false merges and recover exactly the semantic equivalence classes. No relation may be added after protected results are observed.

## Causal ablation

For the source object, remove each retained equation individually and recompute the training congruence. Every removal must destroy exactness.

## Worlds

- source: opaque 4-point transformation world;
- independent transfer: opaque 3-point transformation world;
- non-invertible negative control.

The negative control is not required to obtain a complete bounded presentation under the same short-relation budget, but every retained relation and every induced merge must remain semantically sound.

## Gates

- source theory uses 1..4 relations;
- source bounded training theory exact;
- source protected length-9 theory exact;
- every source relation causally necessary;
- transfer training theory exact;
- transfer protected theory exact;
- transfer uses <=5 relations;
- zero false merges in source, transfer, and negative control.

## Claim boundary

A pass shows verified compact theory formation in a bounded finite setting: short equations generate the same congruence as exact semantics through the declared horizons and transfer to a second source-distinct object.

It does **not** prove the relations form a globally complete presentation for arbitrary word length. Candidate grammar, contextual-congruence machinery, and exact semantic verification are supplied.
