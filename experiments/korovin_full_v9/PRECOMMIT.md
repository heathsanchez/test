# Korovin V9 — Residual-Generated Law Completion

## Frozen question

Can a precise incompleteness residual in a learned mathematical theory generate a previously absent law that closes the theory, is independently sound and causally necessary, and transfers as the same completion operator to new unseen finite transformation worlds?

This experiment is frozen before any V9 transfer world is generated or inspected.

## Source residual

The source is the immutable failed V8 public draw at root phrase `KOROVIN_V8_PUBLIC_BATCH_2026-08-22`, index 7.

V8 independently recorded:

- 17 reachable semantic states;
- 18 theory-induced congruence classes on the bounded audit;
- zero false merges;
- one uncertified canonical transition: representative `abbaa`, token `b`, source word `abbaab`, true canonical target `abba`;
- the inherited candidate-law generator considered equation sides only through length 5, while `abbaab` has length 6.

No V8 rule or result is changed.

## New operator

`RESIDUAL_EDGE_COMPLETION` is frozen as follows.

1. Run the existing V5 theory synthesizer unchanged (`train_h=7`, `candidate_h=5`, `max_rules=10`).
2. Run the existing V6 global certificate unchanged.
3. Collect canonical state-transition edges that are semantically valid but not derivable from the current theory.
4. For every such residual edge form the equation `lhs = canonical_target`.
5. Independently require exact semantic equality of the two sides.
6. Choose the proposal with minimum `(total side length, maximum side length, lhs lexicographic, rhs lexicographic)`.
7. Add exactly that law and rerun the global certificate.
8. Repeat only while a failed certified edge remains, with a maximum of 8 residual additions.
9. Run the existing global redundancy pruning afterward.

The operator may not increase `candidate_h`, enumerate all longer equations, inspect a mathematical object name, or use a target-specific hand-written rule.

## Source gates

The immutable V8 source must reproduce before intervention. The frozen source residual must be exactly `abbaab = abba`. The residual-generated law must:

- be semantically sound;
- change the bounded audit from 18 classes to 17 with zero false merges;
- restore the all-edge global completeness certificate;
- be causally necessary after final pruning.

## Public transfer batch

Root phrase: `KOROVIN_V9_PUBLIC_RESIDUAL_TRANSFER_2026-08-22`.

Exactly 12 indexed worlds, indices 0..11, are generated by the same frozen 4-point/two-generator draw mechanism used in V8. Every draw is reported. There is no rejection sampling, seed replacement, or deletion after results are visible.

For each transfer world the unchanged V5/V6 baseline is run first. Worlds are classified post hoc as:

- `baseline_complete`: the inherited theory is already globally complete;
- `residual_bearing`: at least one semantically valid canonical edge is underivable.

The residual operator is applied only to `residual_bearing` worlds. A baseline-complete world receives no added law.

## Transfer gates

- Exactly 12 indexed transfer worlds are reported.
- At least one transfer world must be residual-bearing; otherwise transfer is untested and the experiment fails.
- Every residual-bearing world must become globally complete under the frozen residual operator within 8 additions.
- Every added residual law must be independently semantically sound.
- After pruning, every retained residual-generated law must be causally necessary for global completeness.
- Final bounded congruence must have zero false merges on every world.
- Baseline-complete worlds must receive zero residual additions.
- No scientific gate may be changed after the transfer draws are generated.

## Claim boundary

A pass supports a specific developmental claim: a verified theory incompleteness residual can construct a missing law outside the original bounded candidate grammar, close the exact mathematical quotient, and reuse the same residual-to-law operator on new worlds.

It does not establish historically novel mathematics or human usefulness.
