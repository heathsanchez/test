# Law Induction V1 — frozen precommit

Goal: test the missing bridge from verified episode evidence to a reusable law that changes held-out capability.

Use eight synthetic arbitrary worlds. Each world exposes verified training observations generated by an episode-specific compositional law over opaque symbols. The held-out query uses a symbol combination absent from the observations. No arm receives the hidden law except ORACLE_LAW.

Arms (matched induction+application budget except oracle ceiling):
- RAW_RECONSTRUCT: infer any reusable rule from the verified observations.
- JOIN_DOTS: explicitly infer latent structure connecting dispersed observations.
- RIVAL_SEPARATOR: form the strongest rival law and prefer the rule whose predictions separate on the observations.
- VERIFIED_RESIDUAL: infer a law using live rivals, residual mismatches, closure-before-invention, and the smallest rule consistent with all verified observations.
- ORACLE_LAW: receives the true hidden law only as a ceiling.

Primary endpoint: exact held-out action accuracy after installing each arm's induced law into a fresh application call. The induction text itself is not scored.

Primary scientific prediction: VERIFIED_RESIDUAL > RAW_RECONSTRUCT on held-out accuracy. Secondary: RIVAL_SEPARATOR > RAW_RECONSTRUCT; JOIN_DOTS > RAW_RECONSTRUCT; ORACLE_LAW defines reachable ceiling. If all non-oracle arms tie, the special methodology is unnecessary on this family. If all arms fail, the family or representation is inadequate.

Frozen model: gpt-4.1-mini; temperature 0; induction max_tokens 180; application max_tokens 60; eight worlds; exact scoring; shuffled call order with fixed seed. No changes after protected run begins.
