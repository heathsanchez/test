# Make Consequence Commute V1 — Frozen Three-Axis Development Test

**Status:** FROZEN BEFORE IMPLEMENTATION / OUTCOME
**Date:** 2026-09-14

## Candidate invariant

Start from an externally grounded interaction/consequence relation. Internal machinery is adequate only where protected consequence can be mediated through it.

For the representational leg:

```math
X \xrightarrow{r} S \xrightarrow{d} K^T,
\qquad
\beta=d\circ r.
```

The invariant under test is:

> **MAKE CONSEQUENCE COMMUTE.**

Operational interpretation:

- if current machinery cannot preserve/realize protected consequence inside its declared class, certify obstruction before expansion;
- if a smaller/cheaper lawful mediator preserves all protected consequence, contract/compile;
- if evidence is insufficient, do not invent a developmental claim.

## One finite world, three sequential inadequacies

The experiment must produce three different certified boundaries in one episode:

1. **Observation-language inadequacy:** the current probe grammar cannot separate two worlds whose protected downstream target differs.
2. **Constructor-language inadequacy:** after the world becomes identifiable, the current action grammar cannot reach the required target.
3. **Realization-class inadequacy:** after exact behavior exists, a new deployment budget makes every exact realization in the current representation family unlawful; another representation family must be acquired that preserves the complete behavior map under the budget.

Finally, old machinery must be removed when consequence-redundant.

## Frozen finite substrate

### Worlds

Two exact relations over 3-bit tuples:

- `E`: tuples of even parity;
- `O`: tuples of odd parity.

The world determines the required navigation target:

```text
E -> node 1
O -> node 3
```

External ground knows the full relation and target mapping.

### Observation grammar O0

O0 contains **all coordinate projections of arity <= 2**, exhaustively.

It does not contain full 3-tuple occurrence queries.

Observation meta-expansion is allowed only after exhaustive proof that O0 cannot separate E/O. The generic expansion rule is arity growth: add the next projection/occurrence arity, not a parity-specific primitive.

O1 therefore becomes the full 3-tuple occurrence-query family if and only if arity-2 closure is certified non-separating.

No named parity predicate is supplied to the observation learner.

### Constructor grammar A0

Navigation state is `Z4={0,1,2,3}`, starting at 0.

A0 is generated by translation `+2 mod 4`. Exhaustive closure is therefore `{0,2}`.

After observation identifies E or O, protected consequence requires reaching target 1 or 3 respectively.

Constructor meta-expansion may enumerate all single translations `+k mod 4`, k in Z4, but may add one only after exhaustive reachability proves the current grammar inadequate.

Minimal lawful constructor additions must be preserved as a frontier if nonunique.

### Realization class R0

Once O1 exists, the exact relation-membership behavior over all 8 tuples is protected.

R0 is an explicit full truth-table representation of both world relations:
- 8 membership bits for E;
- 8 membership bits for O;
- exact semantic cost = 16 stored behavior bits.

A later deployment encounter imposes the frozen representation budget:

```text
MAX_BEHAVIOR_REPRESENTATION_BITS = 8
```

R0 has no legal exact realization under this encoding/budget.

The meta-realization search may then examine a finite declared alternative family: affine Boolean maps on three input bits,

```math
f(x)=b\oplus a_1x_1\oplus a_2x_2\oplus a_3x_3,
```

represented by 4 coefficient bits per world.

The family is acquired only after R0 inadequacy under the deployment contract is certified.

No coefficients are supplied; all 16 affine maps per world must be exhaustively searched.

### Contraction

After an exact <=8-bit affine realization is verified:
- remove the old 16-bit tables;
- replay all 16 protected membership outcomes;
- replay E/O distinction and both navigation obligations;
- ablate the affine realization from the contracted present and require protected membership evaluation to fail.

## Frozen developmental rules

1. **No growth from mere search failure.** Current class must be exhaustively closed for the relevant finite claim.
2. **No outcome-specific hand repair.** Expansion mechanisms are generic arity growth, exhaustive translation enumeration, and exhaustive affine-family search.
3. **No arbitrary winner.** Preserve incomparable minimal constructor additions.
4. **No semantic regression.** Every retained stage replays all earlier protected consequences.
5. **Promotion requires exact independent verification.**
6. **Contraction requires exact protected-consequence replay.**
7. **Ablation must restore the dependency where the acquired mechanism is claimed necessary.**
8. **The experiment may prove only bounded endogenous development inside the declared finite meta-classes.**

## Primary prediction

The same generic developmental discipline should produce the chain:

```text
O0 certified non-separating
  -> O1 full-arity occurrence family acquired
  -> E/O becomes exactly distinguishable

A0 certified unable to reach odd targets
  -> minimal constructor frontier {+1,+3}
  -> protected targets become reachable

R0 certified unable to meet exactness + 8-bit deployment budget
  -> affine realization family acquired
  -> exact behavior preserved in 8 bits
  -> old 16-bit table machinery contracted
  -> affine ablation restores failure
```

## Falsifiers

V1 fails if any of the following occurs:

- O0 contains a separator;
- O1 does not separate E/O;
- the observation expansion is triggered without exhaustive O0 obstruction;
- A0 reaches an odd protected target;
- no single added translation makes both required odd targets reachable;
- a nonminimal constructor is retained while a smaller lawful one exists;
- R0 contains an exact <=8-bit realization under its declared encoding;
- no <=8-bit affine exact realization exists;
- contraction changes any protected consequence;
- affine ablation after contraction leaves the protected behavior fully evaluable;
- any stage requires a parity-specific or outcome-specific rule not frozen above.
