# Meta-Carrier Generator Genesis V6 — Frozen Protocol

## Question

Can the developmental system construct, revise, preserve, and later reuse the **meta-rule that proposes new semantic carriers**, rather than relying on one frozen size-selection rule?

V5 used a frozen generic finite-carrier generator. V6 moves the developmental boundary outward: the carrier materializer remains generic and frozen, but the rule that maps a certified obstruction to a carrier specification is itself a searchable program.

## Frozen lower meta-language

A certified obstruction exposes only two bounded integer observations:

- c = current distinguished-scale summary;
- d = additional distinctions required by the new encounter.

The meta-language has no direct target-size field.

Its primitive expressions are:

- CURRENT
- DELTA
- ONE
- SUCC(e)
- ADD(e1,e2)

A meta-program returns a positive integer carrier specification. The generic frozen materializer then constructs an anonymous finite carrier of that size and the external authority verifies it.

There is no named rule "choose required cardinality", no target projection primitive, and no challenge-specific carrier rule.

## Developmental sequence required

### Encounter 1
Residual (c=2,d=1) requires a size-3 carrier.

The least verified meta-rule should be:

    SUCC(CURRENT)

It may be provisionally retained.

### Encounter 2
Residual (c=3,d=2) requires size 5.

The retained rule fails. Complete bounded meta-search must revise the rule. At minimum two behaviorally distinct cost-minimal rules should remain lawful:

    SUCC(SUCC(CURRENT))
    ADD(CURRENT, DELTA)

Both settle encounter 2, so the system must preserve a lawful frontier instead of choosing by syntax or hash.

### Encounter 3
An independently supplied future consequence (c=5,d=4) requires size 9.

It must separate the frontier:

    SUCC(SUCC(CURRENT)) -> 7
    ADD(CURRENT, DELTA) -> 9

The latter survives and may be compiled as the retained meta-generator.

### Encounter 4
A new residual (c=9,d=6) requires size 15.

With meta-search acquisition budget set to zero, the warm system must reuse the compiled generator and construct a verified size-15 carrier.

A cold system with the same zero acquisition budget must stop conservatively. A cold system with bounded complete meta-search enabled must rediscover a resolving rule.

Ablating only the compiled meta-rule from the warm system must restore the zero-budget obstruction.

## Meta-program quotient

Syntactically different meta-programs are collapsed when their outputs agree on the complete frozen calibration grid:

    CURRENT in {1,...,12}
    DELTA   in {1,...,8}

This collapses commutative duplicates such as ADD(CURRENT,DELTA) and ADD(DELTA,CURRENT) while preserving behaviorally different hypotheses.

## Authority boundary

The developmental kernel never sees the required carrier size directly.

For each proposed carrier spec n:

1. the generic materializer constructs an anonymous carrier of size n;
2. the external authority checks the carrier and exhaustive identity behavior;
3. only an accepted carrier can warrant the meta-rule on that encounter.

Search failure remains distinct from expressive failure.

## Required post-freeze gates

- no target-size projection primitive exists;
- first encounter synthesizes SUCC(CURRENT);
- the first retained rule demonstrably fails on encounter 2;
- encounter 2 yields a genuinely non-canonical two-behavior frontier;
- the frontier is preserved rather than hash-selected;
- encounter 3 independently selects ADD(CURRENT,DELTA);
- selected rule is compiled with provenance across its warranted encounters;
- encounter 4 reuses the compiled rule with zero meta-search;
- cold zero-budget system returns UNKNOWN_META_RULE;
- cold bounded search rediscovers a resolving rule;
- ablation of the compiled rule restores zero-budget failure;
- all generated carriers are anonymous and exhaustively verified.

## Claim boundary

A pass establishes bounded **development of a meta-generator policy** inside a frozen arithmetic program substrate.

It does not establish invention of the arithmetic substrate, invention of the finite-carrier materializer, unrestricted recursive self-modification, or autonomous creation of goals/authority.

The next boundary after a pass is whether the system can develop the **meta-language primitives or evaluator itself** when no program in the current meta-language can generate the required continuation.
