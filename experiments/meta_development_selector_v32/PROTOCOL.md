# Meta-Development Selector V32 — Frozen Protocol

## Question
Can one frozen, semantically anonymous construction kernel choose the minimum structural development required by heterogeneous consequence residuals without being given named repair classes such as memory, relation, context, intervention, joint state, symmetry, grain, or quantum state?

Can recurring obstruction-to-repair structure then be compiled and causally reused on held-out relabellings with less acquisition search, while an active test selector chooses a discriminating encounter when the minimum frontier remains noncanonical?

## Frozen substrate
A record is only a finite binary trace: anonymous channels at anonymous offsets. The kernel receives complete record/consequence tables.

The only representational constructors are:

- constant bit K(b)
- anonymous access A(offset, channel)
- an arbitrary 2-input Boolean map B(op, left, right), where op ranges exhaustively over all 16 truth tables
- recursive composition up to the declared bounded atom/depth limit

The kernel contains no executable repair categories named memory, relation, context, intervention, joint, quantum, symmetry, or grain.

## Developmental selection
For every candidate expression the verifier computes its exact induced signature and asks whether consequence is constant inside each signature class. Accepted candidates are ordered without fitted weights by:

1. number of consequence-relative blocks (coarsest sufficient representation first)
2. number of raw accesses
3. number of binary constructors
4. syntactic depth
5. total trace offset

All exact minima are preserved.

The cold authority is semantic closure of the frozen expression language up to 3 accesses and depth 2.

## Developmental compilation
A solved expression is abstracted to a channel-renaming-invariant skeleton. Only skeletons recurring across independently supplied training worlds are compilable. A warm held-out replay may instantiate compiled skeleton variables over anonymous channels but may not perform cold semantic closure when acquisition search is disabled.

## Active disambiguation
When multiple minimum hypotheses survive, the kernel may inspect only candidate encounter records, not their oracle consequences. It selects the record producing the largest number of distinct predictions across the current minimum frontier, with deterministic index tie-breaking. Only after selection is the hidden consequence revealed and the frontier recomputed.

## Contraction
If an externally supplied current signature is sufficient but strictly finer than the selected minimum sufficient representation, the kernel records verified contraction.

## Post-freeze challenge families
The challenge pack is supplied only after this scientific core is frozen. It will include anonymous worlds whose evaluator-side interpretation spans:

- no growth
- present readout refinement
- historical access
- pairwise joint/relational structure
- higher compositional arity
- context-conditioned structure
- intervention-conditioned structure
- joint-carrier structure
- representational contraction
- noncanonical frontier requiring active discrimination

These semantic labels are evaluator metadata only and are never passed to the kernel.

## Required result
A strong pass requires:

1. all hidden worlds are solved by the same frozen kernel;
2. selected minimum structures match the evaluator-side expected anonymous support/offset/arity constraints;
3. named repair classes are absent from executable kernel identifiers/text;
4. recurring developmental skeletons compile only after independent recurrence;
5. held-out warm replay reaches the same minimum structural class as cold search with strictly fewer tested candidates and zero acquisition search;
6. cold zero-search without compiled developmental memory remains UNKNOWN;
7. developmental-memory ablation restores UNKNOWN in zero-search mode;
8. a noncanonical frontier triggers an intervention selected without oracle access, and the revealed encounter strictly contracts the frontier;
9. a sufficient over-refined current representation contracts to a cheaper consequence-equivalent representation;
10. incomplete authority stays UNKNOWN.

## Claim boundary
A pass establishes a bounded finite proof-of-principle for obstruction-directed structural selection, developmental meta-compilation, active frontier discrimination, and consequence-preserving contraction in an anonymous Boolean trace language. It does not establish unrestricted ontology invention, universal adequacy, quantum reconstruction, natural-world causal discovery, or optimal experimental design.
