# Anonymous Meta-Development Axis Selection V32 — Frozen Protocol

## Question

Can one prospectively frozen developmental kernel choose *which structural direction to grow* from consequence alone, without the challenge announcing whether the missing structure is present detail, history, relation, higher arity, composition, context-conditioning, intervention-conditioning, a joint carrier, contraction, or no growth?

Can repeated verified obstruction→repair episodes then compile into reusable developmental knowledge that preserves the same verified held-out solutions while reducing acquisition search?

## Frozen substrate

The kernel receives only finite rows with numbered banks and an authoritative consequence label. Bank semantics are not named in the kernel.

The construction language contains only low-level anonymous syntax:

- `CONST`
- `READ(bank,index)`
- `PAIR(e1,e2)`
- `TUPLE3(e1,e2,e3)`
- `APPLY(tt,e1,e2)` for an exhaustively enumerated binary truth table
- `SWITCH(selector,e0,e1)`
- nested `APPLY` composition

The kernel does not contain challenge labels such as `present_split`, `higher_arity`, `context_conditioned`, `intervention_conditioned`, `joint_carrier`, or `active_probe`.

## Developmental order

The current language is exhausted in increasing declared structural cost:

1. constant present;
2. single anonymous reads;
3. binary carriers / binary computations / conditional routing;
4. flat arity-3 carrier;
5. nested binary computation.

A candidate is accepted only if its induced partition is *exactly* the authoritative consequence partition. Merely refining the consequence partition is not sufficient.

Thus a later language level is unlocked only after all cheaper declared forms fail to reproduce the coarsest consequence quotient.

## Non-canonicity and active discrimination

If multiple syntax-minimal constructions induce the same exact consequence quotient, the frontier is preserved.

When probe rows are available, the kernel selects the probe that maximizes disagreement among frontier predictions, reveals only that probe's authoritative consequence, and removes candidates that predict it incorrectly.

The challenge pack is frozen only after this kernel is frozen.

## Developmental memory

After a solved world, the kernel records an obstruction fingerprint and the verified structural route that resolved it.

Nothing is compiled after one occurrence.

After at least two compatible occurrences, the kernel compiles a reusable route. Concrete bank roles are anti-unified: positions that recur identically are retained; positions that vary are generalized to wildcards.

On a later matching obstruction:

1. replay the compiled route first;
2. verify the resulting candidate against the full authoritative consequence partition;
3. trust it only if exact;
4. otherwise mark replay failure and fall back to the complete cold developmental search.

This is a cache of verified developmental hypotheses, not an authority bypass.

## Frozen post-challenge gates

M1. One frozen kernel solves every anonymous training family in two relabelled recurrences.
M2. Cold held-out search recovers every hidden developmental family.
M3. Warm held-out search recovers the same verified families.
M4. Meta-routes are compiled only after recurrence.
M5. A deliberately noncanonical case causes the kernel to generate a discriminating probe and collapse the frontier to one survivor.
M6. Warm replay preserves the same verified held-out developmental result as cold search.
M7. Compiled developmental memory reduces acquisition enumeration by at least 4× in aggregate.
M8. Multiple held-out worlds actually use compiled developmental hints.
M9. A deliberately wrong developmental hint is rejected by verification before cold fallback succeeds.
M10. A contraction control selects a consequence quotient strictly coarser than an available raw identity partition.
M11. Incomplete consequence authority remains `UNKNOWN_AUTHORITY`.
M12. Removing verifier authority permits no developmental growth.
M13. Challenge-axis names are absent from the frozen kernel.
M14. The structural DSL is generic rather than physical/domain-named.

## Claim boundary

A pass establishes only a bounded finite result:

- one prospectively frozen generic structural kernel can select among several qualitatively different *supplied low-level construction families* from anonymous consequence structure;
- noncanonical minima can be actively discriminated by a kernel-selected probe;
- repeated obstruction→repair structure can be compiled and safely replayed to reduce later acquisition search;
- incorrect developmental replay remains verifier-revocable.

It does **not** establish unrestricted ontology invention, universal search-language genesis, natural-world causal discovery, autonomous experiment execution outside the declared probe set, or that the supplied low-level DSL is complete.

The central falsifiable advance over the previous sequence is narrower:

> the hidden challenge no longer tells the system which developmental axis to try next.
