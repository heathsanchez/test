# Minimal Anonymous NAND Substrate V33 — Frozen Protocol

## Question

How little structural machinery can be supplied while still recovering the qualitative developmental phenomena previously obtained with named low-level forms such as READ, PAIR, TUPLE3, SWITCH, and APPLY?

V33 removes those named construction families from the scientific kernel.

The frozen kernel receives only:

1. anonymous Boolean input atoms exposed by the encounter interface;
2. one functionally complete Boolean constructor, NAND;
3. finite composition of NAND terms;
4. a verifier that supplies authoritative consequence classes;
5. a structural ordering over representations;
6. an optional declared probe set for active discrimination.

The hidden challenge pack is committed only after this kernel is frozen.

## Frozen term language

A term is exactly one of:

    ATOM(bank_index, coordinate_index)

or

    NAND(term, term)

There is no primitive for reading, pairing, tuples, switching, conditionals, relations, memory, context, intervention, composition families, joint systems, symmetry, or physical/quantum structure.

Input atoms are anonymous encounter symbols. Bank indices have no semantics in the kernel.

A representation may expose zero or more term roots. This is the output interface of the representation, not an additional term constructor. Multiple roots can therefore form a consequence-preserving code without a supplied PAIR or TUPLE constructor.

## Verification and structural order

For a complete finite world, the verifier induces the exact consequence partition Q.

A candidate root set is admissible only when its joint output code induces exactly Q. A finer partition is rejected; preserving consequence labels by over-distinguishing states does not count as the coarsest lawful grain.

Search is ordered by:

1. minimum number of output roots, beginning at the information-theoretic lower bound ceil(log2 |Q|);
2. minimum total number of NAND nodes;
3. minimum maximum term depth;
4. minimum total dependency count.

All candidates tied at the minimum structural metric remain on the frontier.

The term closure is finite and exhaustive through the frozen maximum NAND cost of 5. Semantically duplicate NAND terms retain one minimum witness; equal-cost syntactic aliases among anonymous atoms are preserved so independent probes can discriminate them.

## Active discrimination

If multiple minimum frontiers remain and declared probe rows are available, the kernel fits each frontier representation to known consequences, predicts every probe, chooses the probe maximizing disagreement, reveals only that probe consequence, and eliminates inconsistent frontier members.

## Post-freeze challenge families

The post-freeze harness will contain anonymous worlds whose minimum verified representations are later interpretable as no growth, present distinction, historical/memory distinction, two-coordinate relational code, three-coordinate higher-arity code, composed Boolean computation, context-conditioned computation, intervention-conditioned computation, cross-bank joint code, contraction, and noncanonical minima requiring an active probe.

These labels exist only in the challenge/evaluation harness, never in the frozen kernel.

## Frozen gates

N1. Frozen core hashes match exactly.
N2. One kernel recovers every post-freeze challenge family in three independently relabelled variants.
N3. No-change uses zero term roots.
N4. Present and historical cases require one zero-NAND anonymous atom from different banks.
N5. A four-class case requires exactly two zero-NAND roots without any pair constructor.
N6. An eight-class case requires exactly three zero-NAND roots without any tuple constructor.
N7. A composed Boolean case requires a nonzero NAND program rather than a raw atom.
N8. Context- and intervention-conditioned cases require composed NAND programs drawing on different anonymous banks.
N9. A cross-bank four-class case requires roots spanning two banks without any joint-system constructor.
N10. The contraction control selects a two-class quotient although the full anonymous encounter vector distinguishes many more raw states.
N11. A noncanonical minimum frontier is preserved and an internally selected probe contracts it to one survivor.
N12. NAND ablation preserves raw-atom cases but fails on the composed/context/intervention cases.
N13. Incomplete authority remains UNKNOWN_AUTHORITY.
N14. Verifier ablation authorizes no development.
N15. READ, PAIR, TUPLE3, SWITCH, APPLY and challenge-axis names are absent from the frozen executable kernel.
N16. The only term constructors in the frozen kernel are ATOM and NAND.

## Claim boundary

A pass would establish a bounded finite result, not presuppositionless intelligence.

It would show that several structures previously supplied as separate developmental families can be recovered from anonymous Boolean encounter atoms plus a single functionally complete Boolean constructor, finite composition, verification, and structural minimization.

It would not establish unrestricted ontology invention, universal computation from NAND alone, recursion or unbounded memory, natural-world causal discovery, a unique theoretically minimal prior, that Boolean encounter atoms are themselves derivable, or that the verifier/resource ordering can be removed.

NAND is functionally complete for finite Boolean functions, but this experiment does not claim it is by itself a universal computational substrate. The experiment tests a sharper and more defensible question: how much of the previously named developmental catalogue disappears once construction is reduced to one generic finite Boolean operator?
