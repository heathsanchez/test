# Neighborhood Genesis V36 — Frozen Protocol

## Question

Can supplied adjacency be removed?

V36 gives the scientific kernel a finite set of anonymous binary sites with no edges and no neighborhood relation.

For n sites, the kernel exhaustively enumerates every simple undirected graph on those sites in increasing edge count.

For a candidate graph G and binary site assignment x, the only supplied structural observation is the generic local incidence signature

    multiset_i ( x_i, degree_G(i), number_of_1_neighbors_G(i) ).

Site identities are discarded by sorting this multiset.

A graph is admissible only when the partition induced by this generic local signature is exactly the authoritative consequence partition. Refinements are rejected as excess distinction.

The hidden challenge pack is committed only after this scientific core is frozen.

## Developmental rule

Start from the edgeless graph.

For edge count e = 0,1,2,...:

1. exhaust every graph with exactly e edges;
2. verify whether its local incidence signature induces exactly the consequence quotient;
3. if none succeeds, retain explicit obstruction evidence and authorize the next edge count;
4. stop at the first edge count containing exact solutions;
5. preserve every exact minimum graph;
6. quotient the surviving frontier by graph isomorphism for interpretation.

Thus adjacency is never added because an experiment is labelled "spatial" or "relational". It is added only after every cheaper neighborhood structure is exhausted.

## Authority

Primary tests use all 2^n binary assignments for n=5.

Incomplete authority returns UNKNOWN_AUTHORITY.

Verifier ablation authorizes no topology search.

## Post-freeze challenge family

The challenge harness will create consequences from hidden graph structures after freeze, including:

- no adjacency;
- a single edge;
- two disconnected edges;
- a two-edge path;
- a three-edge path;
- a four-edge star;

The kernel is never told these graph families or their edge sets.

Site permutations and consequence-label relabellings will be applied independently.

Only challenge structures whose exact quotient has a unique minimum isomorphism class under the frozen signature are admitted to the hidden pack.

## Claim boundary

A pass would not establish topology genesis from completely structureless reality.

V36 still supplies:

- stable anonymous site identity within an encounter;
- binary site values;
- the language of finite simple undirected graphs;
- a generic radius-1 local incidence signature;
- edge count as the primary structural cost;
- complete finite authority in the main tests.

What it can establish is narrower:

> neighborhood structure itself need not be supplied. Within a generic finite graph language, verified consequence can force the smallest adjacency relation whose induced local quotient exactly preserves consequence.

If V36 passes, the next remaining handhold is the graph language and local-incidence rule themselves: the system is still told that possible organization should take the form of pairwise undirected adjacency.
