This research-only experiment does not modify the selected Rust Nucleus checker, its original Arena exports, or resource budgets.

The Lean module proves *conditional* constructor evaluation: an actual typed Decidable.isTrue proof yields true, Decidable.isFalse yields false, and a checked true result entails its proposition. A raw observed Boolean alone cannot establish an arbitrary proposition.

The C64 classifier binds the exact frozen n7 source digest and preserves the distinction between standard-budget UNKNOWN (262144) and diagnostic high-budget ACCEPT (14155776). The observed high-budget Boolean is warmed by an earlier high-budget instance exposure; it is not an independently verified low-budget certificate. Missing or forged fields fail closed. Five mutation/evidence tests are expected to pass.

A future promotion requires an actual source-owned, typed constructor/evaluation proof, independently replayed and bound to source, universes, captured environment and proof rules, within the original 262144-unit budget including certificate construction. None of those future obligations is established by this V0.
