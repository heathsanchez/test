# Objecthood Genesis V38 — Frozen Protocol

## Question

Can persistent objects/roles be removed as supplied primitives?

V38 does not begin with a fixed object set.

The weakest recurrence substrate supplied is a finite collection of anonymous recurring boundary marks. A mark is only a low-level recurrence handle: it is not declared to be an object, role, site, channel, or relation slot.

The scientific kernel must decide whether those marks should remain globally exchangeable, be grouped into persistent object classes, and whether incidence between the resulting classes is required.

The hidden challenge pack is committed only after the scientific core is frozen.

## Zero-object baselines

Two representations are available before objecthood:

- VOID: retain no boundary distinction;
- BAG: retain only the global unordered multiset of mark values.

BAG deliberately discards mark identity.

If the authoritative consequence quotient is already preserved by VOID or BAG, the kernel must stop there. It is not allowed to invent objects merely because a partition can be written down.

## Object construction

When the zero-object representations are inadequate, the kernel exhausts every set partition of the anonymous recurring marks.

Each partition block is a candidate persistent object.

The state of one candidate object is only the unordered multiset of values carried by the marks in that block.

Object labels are not exported. The representation retains only the unordered inventory of object states.

Thus objecthood is a quotient over recurrence marks, not a supplied list of named entities.

## Incidence after objecthood

Only after an object partition exists may generic incidence be constructed over its blocks.

The incidence language is inherited in generic form from V37:

1. choose an arity k;
2. choose an ordered word of distinct candidate objects;
3. choose any subgroup of S_k;
4. close the word under that coordinate-permutation subgroup.

No semantic relation type is named.

## Exact verification

A candidate is accepted only when its representation induces exactly the authoritative consequence partition.

Under-distinguishing and over-distinguishing candidates are both rejected.

Rejected candidates retain a finite merge-obstruction or excess-distinction witness.

## Search order

The frozen structural metric is lexicographic.

VOID:
    (0,0,0,0,0)

BAG:
    (0,1,0,0,0)

OBJECTS:
    (
        number of persistent object classes,
        0,
        number of incidence units,
        sum of incidence arities,
        total number of concrete orbit words
    )

There are no tuned scalar coefficients.

The primary bounds are:

- four recurring boundary marks;
- ternary mark alphabet in the hidden complete worlds;
- maximum incidence arity 3;
- maximum incidence units 2.

## Crucial identifiability boundary

V38 does NOT claim persistence can be recovered from completely exchangeable observations with no recurrence information.

That problem is underdetermined.

The experiment deliberately retains the weakest explicit recurrence substrate needed to make persistent object hypotheses falsifiable: anonymous low-level marks may recur, but the scientific kernel is not told which marks belong to the same object or even whether objecthood is required.

The BAG baseline tests whether recurrence identity can be discarded altogether.

## Post-freeze challenge family

The hidden harness will contain consequences whose minimum lawful representations require, after interpretation:

- no retained structure;
- only a global unordered bag, with no persistent objecthood;
- two persistent objects with balanced mark support;
- two persistent objects with unequal mark support;
- three persistent objects plus one generic incidence distinction;
- four persistent objects plus an ordered ternary incidence;
- four persistent objects plus a three-cycle coordinate orbit;
- four persistent objects plus two separate pair incidences.

Independent recurrence-mark permutations and consequence-label relabellings will be applied after freeze.

These semantic descriptions do not occur in the executable scientific kernel.

## Frozen gates

O1. Frozen scientific core remains byte-identical.
O2. One frozen kernel recovers every post-freeze world at the correct minimum metric.
O3. Every primary world has one canonical minimum object/incidence class up to recurrence-mark relabelling.
O4. Constant consequence retains VOID.
O5. Global multiset consequence retains BAG and does not invent a one-object ontology.
O6. Two distinct two-object partition shapes are recovered and distinguished without named object roles.
O7. A three-object world exhausts all zero-, one-, and two-object candidates before three-object persistence is authorized.
O8. An ordered ternary hidden consequence requires four persistent objects plus one ternary incidence.
O9. A cyclic ternary hidden consequence requires four persistent objects and a three-word coordinate orbit.
O10. A two-incidence hidden consequence rejects the entire one-incidence language before two incidence units are authorized.
O11. Recurrence-mark relabelling preserves the canonical recovered object/incidence class.
O12. Consequence-label relabelling preserves the minimum metric and canonical class.
O13. Zero-object ablation preserves VOID/BAG worlds but leaves every object-requiring world CERTIFIED_OBJECT_LANGUAGE_INADEQUACY.
O14. Incidence ablation preserves partition-only worlds but blocks every incidence-requiring world.
O15. Incomplete authority remains UNKNOWN_AUTHORITY and verifier ablation authorizes no object search.
O16. Named object roles, sites, graph/edge types, and hidden challenge-family names are absent from the frozen executable kernel.

## Claim boundary

A pass would not establish object genesis from structureless reality.

V38 still supplies:

- recurring low-level boundary marks;
- finite mark values;
- the language of set partitions;
- unordered multiset state semantics for a partition block;
- generic incidence over candidate blocks;
- finite arity/unit bounds;
- lexicographic structural cost;
- external consequence authority.

What a pass can establish is narrower:

> persistent object classes need not be supplied as the things that relations act on. Given only lower-level recurrence marks, verified consequence can determine whether objecthood is unnecessary, and when it is necessary can force the minimum partition of recurrence into persistent object classes before relational structure is added.

If V38 passes, the remaining handhold is exact and unavoidable in this design: the recurring boundary marks themselves. The next frontier is whether recurrence correspondence can be earned actively from transitions/interventions instead of supplied as a primitive cross-encounter relation.
