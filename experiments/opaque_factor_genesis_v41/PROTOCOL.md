# Opaque State-Space Factor Genesis V41 — Frozen Protocol

## Question

Can the raw positional lattice itself be removed?

V41 gives the scientific kernel an eight-element observable state alphabet:

    X = {x0,...,x7}

These labels are opaque whole-state symbols. The kernel receives no bits, no coordinates, no positions, no adjacency, and no decomposition of one observable state into parts.

It receives only complete intervention-transition tables and externally verified consequence classes.

The hidden challenge pack is committed only after this scientific core is frozen.

## Candidate factorization language

The scientific kernel exhaustively generates Cartesian decompositions of the eight-state set whose factor arities multiply to eight.

The bounded primary shapes are generated from the arithmetic of |X|=8:

    (8)
    (2,4)
    (2,2,2)

A factor is represented only as a partition of the opaque state set into equal fibers.

A complete candidate factorization is generated by:

1. enumerating every bijection between X and the relevant Cartesian code space;
2. taking the coordinate-fiber partitions induced by that bijection;
3. quotienting duplicate value relabellings and duplicate factor orderings.

The executable kernel contains no hidden bit coordinates or challenge factor maps.

## Generic intervention locality

For one candidate factorization and one opaque action token, inspect its complete transition table.

The action is local to candidate factor j only when:

- every other candidate factor is preserved;
- the transformation on factor j is independent of the values of all other factors;
- the transformation on factor j is a nontrivial permutation of that factor's values.

If exactly one factor satisfies those conditions, the action has one candidate target factor.

Otherwise the candidate factorization is intervention-inadequate for that action.

## Consequence quotient

The authoritative consequence labels do not name factors.

They specify only which intervention rows belong to the same verified latent target class.

For a candidate factorization, rows are partitioned by the factor targeted by their opaque action.

A candidate is accepted only if that induced target-class partition is exactly the authoritative consequence partition.

Thus arbitrary factor labels and arbitrary factor-value labels are irrelevant.

## Developmental ordering

Candidate factorizations are searched by increasing number of factors:

    1 factor
    2 factors
    3 factors

All candidates at one factor count are exhausted before a finer factorization is authorized.

No scalar coefficients are tuned.

The one-factor representation is a genuine control: every permutation action is formally local to a single eight-valued factor. Therefore the system must remain unfactorized whenever verified consequence does not require multiple intervention target classes.

## Post-freeze challenge family

After freeze the hidden harness will include:

- a one-target world generated from a finer latent system but whose evidence justifies only one opaque factor;
- a two-target world where one hidden degree remains interventionally unresolved, so the minimum lawful description is two factors and the frontier should preserve unresolved decompositions;
- a three-target world over the same latent state generator, where an additional intervention target class forces a three-factor decomposition and contracts the prior frontier;
- an independently generated two-factor world containing one two-valued and one four-valued latent factor, with actions that require both target classes;
- independent permutations of the eight opaque observable symbols;
- consequence-label relabellings.

The scientific core is never told the hidden Cartesian coordinates.

## Claim boundary

A pass would not establish latent-variable discovery from arbitrary natural data.

V41 still supplies:

- a finite opaque observable state alphabet;
- complete deterministic intervention-transition tables;
- opaque action tokens;
- the generic language of finite Cartesian decomposition;
- the bounded divisor shapes of an eight-element set;
- exact external consequence classes;
- factor count as the structural ordering.

What a pass can establish is narrower:

> the observation space need not arrive with elementary positions or coordinates. Within a finite Cartesian factor language, verified intervention consequence can determine when the whole state should remain atomic, when it should split into latent factors, and when additional intervention classes justify a finer factorization.

If V41 passes, the next frontier is no longer positional segmentation. It is the supplied Cartesian-product ontology itself: whether factor independence/product structure can be earned from a more generic transformation algebra rather than proposed in advance.
