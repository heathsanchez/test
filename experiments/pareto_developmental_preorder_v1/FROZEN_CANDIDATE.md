# Pareto Developmental Preorder V1 — Frozen Candidate

**Status:** FROZEN BEFORE TEST  
**Date:** 2026-09-14

## Candidate

Among already-lawful consequentially sufficient realizations, the developmental economy need not be total or scalar.

For resource vector

```math
c(P)=(c_1(P),...,c_k(P)),
```

define Pareto dominance:

```math
P\preceq Q
\iff
c_i(P)\le c_i(Q)\;\forall i.
```

The lawful developmental residue is the full Pareto-minimal frontier unless the warrant model supplies an additional justified tradeoff/scalarization.

## Predictions

1. incomparable lawful sufficient candidates can both be warranted survivors;
2. arbitrary scalarization can select different survivors;
3. positive monotone weights never select a Pareto-dominated candidate, but they can erase legitimate incomparability;
4. adding a justified resource bound or lexicographic policy can lawfully collapse the frontier.

## Falsifier

V1 fails if a unique total preference is always derivable from the Pareto data alone, or if the Pareto frontier ever contains a dominated candidate.
