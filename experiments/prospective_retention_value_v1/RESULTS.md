# Prospective Retention Value V1 — result

`VERIFIED_PROSPECTIVE_RETENTION_VALUE` in the finite scarce-state causal
prospective qualification.

With capacity fixed at three structures, fully charged totals were: exact
hindsight oracle 1002; geometry-aware 1120; depth 1317; scope 1322.5;
persistence 1898; sham 2135.5; accumulated amortization 2382. Unlimited
retention cost 1056 and is an accounting reference, not a feasible scarce-state
competitor.

At the frozen midpoint, the geometry estimator nominated `late_huge`. Its
forced suffix removal added 1032 calls, versus 360 for the depth nominee and 312
for the scope nominee. Amortization and persistence happened to nominate the
same node and therefore tied this causal penalty.

The result shows that a multi-coordinate online estimator can prospectively
allocate scarce persistent state better than any tested scalar policy. It does
not establish estimator learning, natural-world forecasting, global optimality,
or open-ended retention.
