# Recurrence Without Frequency V9 — Frozen Protocol

## Question

Can temporal recurrence, period-like structure, and phase-like equivalence emerge from the V8 relational substrate without supplying FREQUENCY, PERIOD, CYCLE, PHASE, or ITERATE as semantic primitives?

V8 reduced the finite object-language basis to:

    BIT seed + RELATION + COMPOSE

with verified reification in the developmental constitution.

V9 adds no new semantic primitive. It only allows the frozen kernel to repeatedly use COMPOSE and consequential equivalence over finite future traces.

## Frozen substrate

The kernel receives:

- a finite carrier X;
- a verified deterministic transition relation T : X -> X;
- optionally, a verified observation relation O : X -> B into a finite observation carrier B;
- a finite search horizon.

The kernel may:

1. construct relational powers by repeated COMPOSE;
2. compare constructed relations extensionally;
3. search for the least positive k for which T^k equals the identity relation;
4. if an observer is present, construct finite future observation traces by composing O with T^j;
5. identify states whose complete admitted future traces are equal;
6. reify those equivalence classes as a new carrier.

No primitive or challenge hint names the result as period, cycle, phase, frequency, oscillator, or clock.

## Required post-freeze challenges

### R1 — 3-step recurrence
A six-state transition consists of two structurally identical three-step orbits. The least positive identity-return exponent must be discovered as 3.

### R2 — consequence-derived phase classes
A binary observation relation is chosen so that complete one-return traces distinguish three positions but identify the two copies. The kernel must construct exactly three future-trace equivalence classes, each containing one state from each copy.

### R3 — unseen 4-step transfer
A separate eight-state transition with two four-step orbits and a different observation pattern must yield least identity-return exponent 4 and four future-trace classes under the same frozen kernel.

### R4 — incomplete-horizon honesty
On the four-step system, horizon 3 must return UNKNOWN_RECURRENCE rather than falsely certifying no recurrence.

### R5 — non-global recurrence control
A deterministic transition with a transient feeding a fixed point must not be misclassified as a global identity-return recurrence inside the declared bound.

### R6 — causal COMPOSE ablation
With COMPOSE disabled, recurrence beyond one transition step and future-trace class construction requiring multi-step propagation must fail or remain UNKNOWN.

### R7 — recurrence compilation
After the same relational recurrence signature is independently verified on two distinct isomorphic systems, the kernel may compile an anonymous recurrence-analysis capability and apply it on a third isomorphic system with zero structural-search acquisition.

## Claim boundary

A pass establishes only that, in bounded finite deterministic systems, recurrence and phase-like quotient structure can be derived from relation composition plus consequence-relative future-trace equivalence.

It does not establish continuous frequency analysis, Fourier structure, waves, physical time, natural-world oscillators, or that all temporal semantics reduce to finite recurrence.

The next boundary is spatial structure: whether locality, adjacency, lines, regions, and field-like representations can be constructed from raw channel trajectories without supplied coordinates.
