# Semantic Carrier Genesis V5 — Frozen Protocol

## Question

Can a frozen developmental system add a genuinely new finite ground-type semantic carrier when the current object-level type algebra is structurally incapable of expressing the required cardinality, and can that new carrier later create signatures that were impossible in the old algebra?

V4 learned only a macro type constructor whose semantics expanded back into Bool/Product. V5 crosses that boundary.

## Object-level basis before development

The active object basis initially contains only:

- Bool, with cardinality 2;
- Product(A,B), with cardinality |A|*|B|.

Therefore every object type generated from the initial basis has cardinality 2^k.

No odd-cardinality ground type and no generic finite carrier constructor is present in the initial object basis.

## Frozen meta-substrate

The frozen developmental meta-substrate contains one generic capability:

> construct an anonymous finite carrier atom of size n, for bounded positive integer n, with canonical opaque values and a generic identity/equality interpreter.

This mechanism is not part of ordinary object-language reach until certified obstruction authorizes its use.

It is generic: it does not contain special cases for 3, 5, 6, or any named mathematical structure.

## Authorization rule

Basis growth is authorized only after:

1. current object-level search fails;
2. the external residual specifies the required finite cardinality;
3. a structural completeness check proves that cardinality is outside the multiplicative monoid generated by the current ground-carrier cardinalities under Product.

For the initial basis {2}, this proves every reachable cardinality is a power of two.

Only then may the bounded meta-generator propose new anonymous carriers. Every proposed carrier is independently checked by the external authority before admission.

## Learned semantic atom

An admitted carrier is content-addressed and stores:

- anonymous carrier id;
- exact cardinality;
- canonical finite values;
- earning encounter;
- external warrant digest;
- structural obstruction certificate showing why the prior basis could not generate the required cardinality.

Unlike V4, the new carrier has no macro expansion into the old Bool/Product algebra.

## Causal transfer

After a size-3 carrier is earned, freeze further basis-growth budget and require a new type of cardinality 6.

Warm basis:

    {Bool(2), learned_carrier(3)}

can construct Product(carrier3, Bool) with cardinality 6.

Cold initial basis:

    {Bool(2)}

cannot construct cardinality 6 at any Product depth, because every reachable cardinality is a power of two.

Ablating only the learned carrier from the warm basis must restore certified impossibility under the same frozen transfer conditions.

## Program layer

Every accepted type is used as both input and output of an identity program. The external authority exhaustively checks identity on every finite value, so a carrier is not admitted merely from a cardinality declaration.

## Required post-freeze gates

- initial object basis has only Bool/Product semantics;
- exact cardinality 3 is structurally impossible in the initial basis;
- basis growth is not invoked before certified structural obstruction;
- generic meta-search constructs and verifies exactly one anonymous size-3 carrier;
- learned carrier is not macro-expandable to the old basis;
- later cardinality-6 signature is constructed from learned carrier × Bool with basis growth disabled;
- cold initial basis certifies cardinality 6 impossible even with unbounded Product nesting;
- ablation of learned carrier restores the same impossibility;
- warm transfer identity program is exhaustively verified;
- a deliberately insufficient but potentially generable bounded search returns UNKNOWN_SEARCH rather than expressive failure;
- no challenge-specific carrier semantic is added post-freeze.

## Claim boundary

A pass establishes bounded verified **semantic carrier genesis** from a supplied generic finite-carrier meta-substrate.

It does not establish spontaneous semantics from no substrate, natural-world grounding, arbitrary inductive-type invention, dependent type genesis, or autonomous invention of the finite-carrier generator itself.

The next boundary is whether the developmental system can construct or revise the **meta-rule that generates new semantic carriers**, rather than merely invoke a frozen generic one.
