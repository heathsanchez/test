# Spatial Structure Without Coordinates V10 — Frozen Protocol

## Question

Can locality-, line-, ring-, and region-like structure be constructed from anonymous causal channel consequences without supplying coordinates, geometry, adjacency, distance, line, boundary, region, graph class, or topology labels?

V8 reduced the finite object substrate to relation + composition with verified reification.
V9 tests temporal recurrence without frequency primitives.
V10 asks whether spatial organization can likewise arise as verified relational structure.

## Frozen inputs

A world supplies only:

- N anonymous channels;
- a set of one-step impulse experiments;
- for each observed source channel i, the binary set of channels whose next state changes under that impulse.

The frozen kernel receives no coordinates, positions, distances, dimensions, or neighborhood labels.

## Frozen kernel operations

1. For each observed source channel, exhaust the 2^N possible outgoing relation rows and retain the unique row accepted by the external consequence record.
2. If every source row is verified, assemble the typed influence relation R on channels.
3. Using only repeated relational COMPOSE, propagate reachability up to the complete finite bound N-1.
4. Define consequential connectivity equivalence:
       i ~ j iff j is reachable from i and i is reachable from j
   within the complete bound.
5. Reify the resulting equivalence classes as anonymous component/block carriers.
6. Compute only generic relation invariants needed for replay:
   in-degree, out-degree, verified reach depth, component sizes.
   The kernel does not label any structure as line, ring, region, dimension, or geometry.

## Required post-freeze worlds

### S1 — hidden path
An anonymous permutation of a seven-channel undirected path. The reconstructed influence relation must exactly match the hidden relation under the supplied channel identities. Generic invariants should expose one connected component, two degree-1 endpoints, and five degree-2 internal channels.

### S2 — hidden ring
An anonymous permutation of an eight-channel ring. The same frozen kernel must reconstruct one component with all degree 2 and finite return connectivity, without being given a ring primitive.

### S3 — disconnected blocks
An anonymous seven-channel world containing a 3-path and a 4-path. The kernel must construct exactly two consequential connectivity classes of sizes 3 and 4 and reify them.

### S4 — incomplete observation honesty
With one source-channel impulse withheld, the kernel must return UNKNOWN_INFLUENCE rather than fill the missing row.

### S5 — COMPOSE ablation
With COMPOSE disabled, local influence rows may still be reconstructed, but multi-step reachability/component reification that depends on indirect paths must remain unresolved.

### S6 — permutation invariance
Two differently relabelled copies of the same path world must yield the same canonical invariant signature even though no coordinates or channel names align.

### S7 — causal compilation
After two independently verified path signatures, the kernel may compile an anonymous structural signature atom. On a third relabelled path, it may test the retained signature directly with zero signature-search acquisition. A cold zero-acquisition kernel must remain UNKNOWN_STRUCTURE. Ablation restores the cold behavior.

## Claim boundary

A pass establishes only that bounded finite spatial-like organization can be reconstructed as causal relational structure from anonymous intervention consequences.

It does not establish metric geometry, continuous space, physical locality, Euclidean dimension, natural-image objecthood, or field theory.

The next boundary is wave dynamics: whether temporal recurrence plus coordinate-free spatial relations can reconstruct mode-like/nodal structure from raw simulated vibration data without being given frequency, phase, nodes, eigenmodes, or geometry labels.
