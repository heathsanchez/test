# Transformation-Algebra Genesis V43 — Frozen Protocol

## Question

Can even the quotient/equivalence-relation search ontology be removed?

V43 receives only:

- a finite opaque state set X;
- complete bijective transformations of X indexed by opaque action tokens;
- verified consequence classes over those actions.

The frozen scientific kernel does not enumerate state partitions, quotient candidates, Cartesian coordinates, latent factors, graph structure, or hidden component maps.

Its only constructive operations are generic finite transformation-algebra operations:

- permutation composition;
- subgroup generation by closure;
- subgroup orbits on the opaque state set;
- induced action on an orbit family when well-defined;
- commutation and subgroup-intersection checks.

## Consequence classes as generators

Verified consequence groups opaque actions into classes C_1,...,C_k.

For each class C_i, define algebraically:

    G_i = subgroup generated by the transformations in C_i.

Let:

    G = subgroup generated by all observed action transformations.

No latent representation is proposed.

## Derived carrier for one action class

For class C_i:

1. generate H_i from every action outside C_i;
2. compute the H_i-orbits on X;
3. ask whether G_i maps whole H_i-orbits to whole H_i-orbits.

If not, class i is recorded as COUPLED_NONNORMAL_ACTION.

If yes, G_i induces a transformation group on the H_i-orbit family.

The kernel records only algebraically forced statistics of that induced action:

- number and sizes of H_i-orbits;
- order of the induced G_i action;
- number and size of induced action orbits.

No candidate partition was searched; the orbit family is derived from subgroup closure.

## Global classifications

If consequence contains only one action class, V43 stops undecomposed. Rich hidden transformation structure is not enough by itself to justify components.

For multiple classes, the kernel distinguishes:

### DERIVED_DIRECT_COMPLEMENTARITY

Only when all of the following hold:

- every class has a well-defined derived carrier;
- all class subgroups commute pairwise;
- their pairwise intersections are identity only;
- the product of class-subgroup orders equals the generated full-group order;
- the full generated group acts regularly and transitively on X.

This is a derived algebraic fact, not a searched Cartesian state representation.

### UNDERRESOLVED_MULTIPLE_STATE_ORBITS

When class subgroups are mutually compatible in the same sense but their generated action has multiple state orbits.

This records residual state distinctions not identified by current transformation classes.

### COUPLED_ACTION_ALGEBRA

When the observed transformation classes fail the direct-compatibility conditions, including noncommutation or failure to induce a lawful action on another class's orbit family.

The kernel must not force a component interpretation in this case.

## Primary finite scope

Primary hidden worlds use eight opaque states.

Unlike V42 there is no Bell-number search and no enumeration over representation candidates.

The amount of construction is determined only by closure of the observed transformation generators.

## Post-freeze challenge family

Only after the scientific core is frozen, the harness will instantiate:

- a rich hidden three-generator system whose actions are all assigned one consequence class; it must remain undecomposed;
- the same hidden generator with two verified transformation classes; the generated action should be underresolved because one latent transformation family remains unobserved;
- the same generator with three verified transformation classes; its three class subgroups should become directly complementary algebraically;
- an independently generated two-class system whose class subgroup orders are 2 and 4 and whose full action is regular/transitive;
- a noncommuting two-class regular action algebra of order 8; numerical group-order factorization must NOT be mistaken for independent components;
- independent relabellings of the opaque state set;
- consequence-label relabellings.

The hidden challenge generators may use coordinates/group names internally. None occur in the frozen kernel.

## Claim boundary

A pass would not establish unrestricted representation invention from arbitrary dynamics.

V43 still supplies:

- a finite opaque state set;
- complete bijective transformation tables;
- verified action classes;
- group closure as the algebraic substrate;
- subgroup orbits as a generic consequence of group action.

What a pass can establish is narrower:

> state-space components need not be proposed as Cartesian factors or searched as equivalence relations. They can appear as derived invariants of the transformation algebra: other-action subgroup orbits, induced held-out actions, and direct-complementarity conditions forced by the observed generators.

If V43 passes, the remaining handhold is now the assumption that interventions are bijective permutations forming a group-like algebra. The next frontier is to admit irreversible/noninvertible transformations and ask whether group, semigroup, quotient, order, or other structure is itself selected by consequence.
