# Transformation-Quotient Genesis V42 — Frozen Protocol

## Question

Can the supplied Cartesian-product ontology of V41 be removed?

V42 receives only:

- a finite opaque state set X;
- complete bijective transformations of X, indexed by opaque action tokens;
- verified consequence classes over those actions.

The scientific kernel contains no Cartesian code space, no factor arity, no hidden coordinates, and no product search.

Its only candidate structural language is the set of all equivalence relations on X.

## Generic quotient semantics

An equivalence relation is represented by a set partition P of X.

For one action g:

1. apply g to every state in one block of P;
2. ask whether the whole block maps into one block of P;
3. if every block maps bijectively to another block, g induces a lawful permutation of the quotient X/P.

If any block splits across quotient blocks, P is not invariant under g.

For an invariant quotient, g is:

- invisible on P when every quotient block is fixed;
- visible on P when the induced quotient permutation is nontrivial.

No semantic meaning is attached to a block or quotient.

## Consequence-gated quotient witness

Verified consequence partitions the opaque actions into action classes.

For one verified action class C, a quotient P is an exact witness only when:

- every action in C is visible on P;
- every action outside C is invisible on P;
- every action preserves P as an equivalence relation.

Thus a quotient says only:

    there exists a distinction in state space changed exactly by this verified transformation class.

The kernel searches all set partitions of X by increasing block count and retains every minimum exact witness.

Fewer quotient blocks are preferred because they retain less structure.

## Zero-decomposition baseline

If all opaque actions belong to one verified consequence class, no quotient is needed to distinguish them.

The kernel returns the opaque state space undecomposed.

This prevents the presence of a rich hidden generator from forcing latent structure that consequence does not require.

## No product primitive

The scientific kernel does not combine quotient witnesses into products.

After the core is frozen, the evaluation harness may inspect a recovered family of quotient witnesses and ask generic set-theoretic questions:

- what is their common refinement?
- are all common-refinement cells singletons?
- does the product of quotient cardinalities equal |X|?

Only if those conditions happen to hold may the harness describe the recovered quotient family post hoc as complementary Cartesian coordinates.

If the common refinement is not discrete, the result remains underresolved.

If the common refinement is discrete but quotient cardinalities overcount |X|, the result is constrained/subdirect rather than a full product.

These interpretations are not candidate structures available to the frozen kernel.

## Primary finite scope

Primary worlds use |X| = 8.

The frozen kernel exhaustively generates all Bell(8) = 4,140 set partitions.

The action tables are complete deterministic permutations of X.

## Post-freeze challenge family

After freeze, the hidden harness will include:

- one verified transformation class generated from a richer latent action system; the kernel must remain undecomposed;
- two verified transformation classes from a hidden three-degree system; the kernel must recover quotient witnesses but preserve residual underdetermination;
- the same hidden generator with a third transformation class; the recovered minimum quotient family should contract to three unique complementary binary quotients;
- an independently generated two-class system with hidden 2-by-4 organization; the minimum quotient witnesses should have cardinalities 2 and 4;
- independent permutations of the eight opaque state labels;
- consequence-label relabellings.

The hidden challenge generator may use coordinates internally. The frozen scientific kernel never receives or mentions them.

Q13. Limiting quotient size to two blocks preserves the binary three-class world but blocks the hidden 4-valued quotient in the 2-by-4 world.

## Claim boundary

A pass would not establish unrestricted ontology invention.

V42 still supplies:

- a finite opaque state set;
- complete bijective action tables;
- the generic language of equivalence relations / quotients;
- verified action classes;
- block count as structural ordering.

What a pass can establish is narrower:

> independent-looking components need not be proposed as Cartesian factors. Verified transformation classes can first force minimal invariant quotients. Cartesian complementarity, when it occurs, can then appear as a derived property of those independently earned quotients rather than as the search ontology.

If V42 passes, the next remaining handhold is the quotient/equivalence-relation ontology itself. The next frontier is to begin from the transformation semigroup/group algebra alone and derive invariant quotients or other representation types from algebraic obstruction without enumerating set partitions as the privileged structural language.
