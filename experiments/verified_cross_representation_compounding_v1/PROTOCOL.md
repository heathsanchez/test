# Verified Cross-Representation Compounding V1 — Frozen Protocol

## Question

Does an acquired developmental procedure reduce the fully charged acquisition cost of a held-out developmental procedure after the carrier, operation names, field encoding, and token vocabulary change, with no direct macro-token reuse?

## Frozen source and held-out target

Source programs use `SCAN FILTER FIRST PAIR EXTEND TEMPORAL`. The target graph-record carrier uses six disjoint opaque tokens and different coordinate encodings (`edge-*`, `lag-edge-*`). Source `D2` is retained only as a typed sequence of semantic roles.

Before target search, a frozen adapter exhaustively compares every source role against every opaque target operation on all six declared interface cases. A role is instantiated only on a unique complete behavioral match. Every adapter verifier call is charged. The target answer is not available to the adapter.

The held-out target requires acquisition of a developmental procedure that introduces temporal graph-edge coordinates and constructs the least two-coordinate cover. Source `D2` alone cannot solve it; it can only compress the static developmental subprocedure.

## Search and controls

Target programs are enumerated level-completely by token length. All programs at the first successful level are evaluated. Direct source tokens are absent.

- `COLD_IMMEDIATE`: opaque target primitives only.
- `Q_WARM`: target primitives plus the behaviorally instantiated developmental macro; compilation probes are charged.
- `Q_ABLATION`: remove the transferred macro.
- `SHAM`: add an inert matched macro slot.
- `ANSWER_MEMORY`: expose earlier source selections without the acquired procedure.

Primary metric: all verifier probes during compilation and acquisition. Correctness, search nodes, candidate evaluations, depths, and adapter calls are secondary metrics.

## Precommitted pass

All conditions must remain correct; fully charged `Q_WARM < COLD_IMMEDIATE`; ablation must restore cold; sham and answer-memory must not reproduce the gain; source and target vocabularies must be disjoint; and every transferred role must have a unique exhaustive behavioral-equivalence certificate.

## Claim boundary

A pass earns bounded, prospective, causal cross-representation transfer and compounding through a supplied typed semantic interface. It does not establish natural-domain transfer, learned adapter discovery, unbounded compounding, or substrate genesis.
