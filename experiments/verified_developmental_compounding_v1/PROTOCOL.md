# Verified Developmental Compounding V1 Protocol

## Frozen question and claim boundary

This deterministic qualification asks whether a single generic controller, retaining only verifier-admitted reusable operations, reduces the verifier-mediated cost of later capability acquisition. It tests three supplied finite adapters: exhaustive two-bit theorem evaluation, executable string-program synthesis, and exact grid-rule induction. Four cumulative tasks are fixed per adapter. This is a bounded causal experiment, not evidence of unrestricted self-development or natural-task generality.

## State and authority

Active state contains typed primitive capabilities only. It cannot contain task outputs or final solution programs. Full provenance is written separately. Every admission records its generating residual, candidate, verifier authority, preservation replay, dependencies, reason, and later ablation result. The update is additive: the prior state is not rewritten.

The theorem adapter exhaustively evaluates the complete declared two-bit carrier. The program and rule adapters use exact executable replay over frozen complete specification sets. These authorities establish correctness only relative to those declared finite specifications.

## Frozen controller and ordering

The controller, operation order, maximum program depth four, task ordering, seed 20260911, metrics, controls, and gates are frozen in the first experiment commit. Candidate enumeration is deterministic. No model or API is used.

For each later task:

- COLD begins at empty active state.
- WARM begins with preceding admitted primitives from that domain.
- ABLATION removes the earliest retained primitive predicted to be on the protected prefix.
- SHAM has the same capability-record count but inert capabilities from an unrelated type.
- ANSWER MEMORY has prior outputs in provenance only; active state remains empty and the controller has no answer-reading interface.

Primary cost is verifier calls to first accepted program. Search nodes equal verifier calls in V1. Also record correctness, residual count, CPU and wall time, active-state size, retained state, dependencies, and provenance size. Tokens are null because no external model is used.

## Prospective transfer

After the theorem and program domains exhibit the same residual-guided composition pattern, the abstract operator `residual_guided_composition` is compiled and hashed. Only then is held-out rule-induction task C4 exposed. C4 compares COLD, PI-WARM, PI-ABLATION, and matched inert PI-SHAM. The operator code is not modified after exposure.

## Precommitted pass gates

1. No warm correctness regression.
2. Aggregate later-task cold cost is at least twice warm cost.
3. Warm benefit persists at every later stage.
4. Targeted ablation damages cost or reachability.
5. Sham state does not reproduce the gain.
6. Prior answers without admitted capabilities do not reproduce the gain.
7. Frozen Pi improves the prospective held-out task.
8. Pi is frozen before held-out exposure.

Failure of any gate prevents the strong verdict. Implementation defects are repaired and rerun; scientific failures are preserved.
