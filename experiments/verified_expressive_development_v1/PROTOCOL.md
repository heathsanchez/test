# Verified Expressive Development V1 Protocol

## Primary question

Can a reality-facing finite adapter inhabit the complete typed transition from search uncertainty to certified expressive inadequacy, construct a capability outside the current language, externally verify and admit it, resolve the residual while preserving old consequence, and recover the obstruction under removal ablation?

## Frozen domain

The carrier is the complete set of two-input Boolean functions, represented by four-bit truth tables.

- Initial atoms: constant false, constant true, first projection, second projection.
- Initially admitted constructor: Boolean negation.
- Initial semantic closure is computed to a fixed point.
- Residual target: conjunction.
- Prospective reuse target: first input AND NOT second input.
- Ambient proposal basis contains one not-yet-admitted generic constructor: pointwise binary meet.

The proposed capability is a reusable binary constructor, not a stored final program. All 16 input truth-table rows form the finite universe. Closure computations are exhaustive.

## Required causal chain

1. Emit `UnknownSearch` before closure completion.
2. Exhaustively compute the old semantic closure.
3. Certify both completeness and absence of a resolving old program.
4. Bind both certificates to an immutable SHA-256 snapshot digest.
5. Inhabit `UnknownExpressivity` only after both certificates exist.
6. Construct pointwise meet outside the old language.
7. Verify the constructor on all Boolean input pairs.
8. Admit it only through the typed generator-proposal transition.
9. Recompute closure; resolve the residual.
10. Preserve every old semantic function.
11. Resolve the predeclared reuse target.
12. Remove the generator; both new capabilities must disappear.

## Negative controls

Admission must reject missing-completeness evidence, missing-negative evidence, a stale snapshot digest, and a candidate already represented in the old semantic closure.

## Pass criterion

`VERIFIED_EXPRESSIVE_DEVELOPMENT` requires every required chain element and every negative control to pass in both the executable evidence generator and Lean. This is a bounded finite result, not unrestricted generator genesis.
