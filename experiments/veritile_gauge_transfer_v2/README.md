## New residual

The source-specific exponential algebra is larger than the consequential law.
The quotient does not care *why* numerator and denominator acquired the same
nonzero factor.

The candidate compiled law is therefore:

```
(c·N') / (c·D') = N' / D'      when c ≠ 0
```

or, in evidence-facing form:

if `c·N' = N` and `c·D' = D`, then `N'/D' = N/D`.

This is the smallest common-factor / gauge-cancellation capability implied by
the successful V1 transfer.
