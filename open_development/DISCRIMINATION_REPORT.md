## First necessary separator

The existing external eligibility predicate is not route-neutral. It requires
successful global-quadratic certification AND successful power-zero ray-square
replay before a theorem enters the candidate pool. Every admitted candidate
therefore already has a supplied lawful role-only realization. The frozen
initial capabilities have ray/interval contracts, not the all-real target role.
With that initial state each eligible task is exaptation; after role acquisition,
later tasks may become reuse. Neither regime supplies certified expansion.

We retain the canonical corpus, parser, state, and role grammar and audit this
boundary before attempting a scoring stream. This is an administrator coverage
audit, NOT implementation or qualification of a four-way developer. No route
predictions, scored tasks, new scoring admissions, confusion matrix, or v4
release are emitted. Out-of-parser statements are excluded, not manufactured
UNKNOWN scoring tasks. There is no claim that all of MiniF2F lacks route diversity.

## Frozen execution protocol

The first CI job tests the existing core plus internal synthetic coverage fixtures,
checks exact source ancestry, asserts the external path is absent, acquires the
canonical retained source, and uploads its ledger and source-file manifest.
Only a subsequent job checks out the pinned external corpus. It verifies commit,
Git blob SHA1, and file SHA256, audits every candidate, and records a deterministic
nonce-derived order using run ID and attempt. It independently checks each
normalized quadratic's square identity with rational arithmetic. A separate
process recomputes the evidence from source bytes before upload. This is
recomputation, not an independent parser or human-blinded evaluation.

## Authority and next boundary

This audit is Python-qualified. It adds no Lean theorem and does not change
`Developer.run`, the MSI kernel, adapters, or v3 release authority. Existing Lean
authority concerns refinement, finite/constructor realizations, and the previously
qualified proof-program semantics, not this coverage algorithm.

The next protocol must define a route-neutral external observation/eligibility
boundary and a complete effective-language semantics before scoring. In
particular, success under a proposed role must NOT be an eligibility prerequisite.
No additional corpus was selected merely to supply a desired expansion label.
Any broader protocol is a new scientific freeze, not a repair of this scoring run.
