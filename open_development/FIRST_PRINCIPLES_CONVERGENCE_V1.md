# First-Principles Convergence V1

## Scientific basis

This experiment starts from the frozen Open Development release-v4 source commit:

`01088c9e67b11cc29342b5150a28050bdef16b29`

It does not inherit the later continuation, interaction-quotient, gauge, Chu, Ludics, FCA, or other interpretive experiment branches. The only concrete substrate used is the release-v4 runtime, its verifier-gated state mechanism, and the declared finite grid operators.

The purpose is to ask what remains when names and interpretations are removed.

## Questions

1. Do duplicate descriptions create new witnessed behavior?
2. Can finite observational agreement be mistaken for identity?
3. Can a new observation resolve such underdetermination?
4. Does failure to find a separator prove equality?
5. Can a verified new ability be added without changing old behavior?
6. Do two independently verified additions depend on order?
7. Does archival history affect future behavior after active state is exactly restored?
8. What happens when no declared change is justified?

## Results

### Observed fact 1: duplicate description is not new witnessed behavior

The baseline finite capability/task table is 8 by 8. Adding one semantically duplicate capability record and one duplicate task makes the raw table 9 by 9, while collapse by identical outcome profile returns exactly 8 by 8.

This establishes only the declared finite table result. It does not establish global semantic identity from finite agreement.

### Observed fact 2: finite non-separation is insufficient for global identity

A fresh family of 44 expressions was evaluated exhaustively on all 16 binary 2 by 2 grids. They formed 34 observational classes. Two of those classes split when evaluated on the broader family of all binary 2 by 3 and 3 by 2 grids.

Therefore agreement on the first finite observation family did not license global identity.

### Observed fact 3: a separating observation can resolve underdetermination

For one pair that agreed on every binary 2 by 2 grid, the finite search found a 2 by 3 input on which the outputs differed. Revealing one branch's output reduced the unresolved pair from two candidates to one.

### Observed fact 4: non-separation alone is not equality authority

Failure to separate descriptions over a declared observation family is recorded only as non-separation. Equality requires an independent reason, such as identical certified description or a genuinely exhaustive closed semantic domain.

### Observed fact 5: verified addition can preserve old behavior

A task requiring a new composite behavior had no solution in the old direct/role behavior families. One verified new record was admitted. All eight old executable records were then replayed on all 16 binary 2 by 2 grids: 128 old behavior checks were unchanged.

This is a finite preservation result for the tested addition.

### Observed fact 6: two tested independent additions commute operationally

Two independently verified additions were applied in both orders. The final active semantic record sets were identical in the two runs.

This is a result for the tested pair, not a universal commutativity theorem.

### Observed fact 7: archival history was not an active cause after exact restoration

One state learned an addition and then exactly revoked it. Its active state became identical to a cold state, while its append-only ledger remained longer. The same future verified addition was then applied to both states. They produced the same verdict and same final active semantic records.

Thus, in this runtime and fixture, ledger history alone did not alter future development once active state was restored.

### Observed fact 8: no justified change means no active change

A task outside all declared repair families produced UNKNOWN, retained no record, and left the active state unchanged.

## Smallest structure currently supported

The observations can all be described without importing any named theory.

There is:

- a current set of realizable behaviors;
- a current set of observations/tests;
- an outcome for applying a behavior to a test;
- a distinction relation induced by those outcomes relative to the declared observation set;
- a rule that new evidence may add an observation, add a verified realization, or justify no active change;
- a preservation condition requiring old witnessed behavior to remain unchanged under a conservative addition;
- a separate audit history recording authority without automatically becoming active causal state.

The finite observations support the following two operational rules:

1. Do not identify descriptions merely because a bounded observation set failed to separate them.
2. Do not alter active behavior unless a verified reason licenses the alteration, and preserve prior witnessed behavior when extending.

## Not established

This experiment does not establish:

- a universal ontology;
- global semantic equivalence from finite observation;
- universal order independence;
- unrestricted synthesis of new languages or constructors;
- self-duality of the implementation;
- that every useful future system must use this exact representation;
- any physical, categorical, logical, or philosophical interpretation.

Those may be compared later, after the operational structure is frozen.
