as V1, a richer finite typed object-centric spatial substrate was exhaustively
enumerated and independently replayed. Across 400 ARC evaluation tasks, its

This does not establish that object-centric programs cannot solve these tasks,

## Next smallest separator

The evidence points away from another blind combinatorial widening. V2 added
the requested object primitives, but its grammar mainly renders a selected
object back into an input-sized canvas and lacks relational programs that
compute output geometry and correspondence between multiple selected objects.
A successor should first inspect the 400 certified residual shapes and declare
the smallest finite relational/output-construction extension before refreezing.
Candidate additions should be justified by residual classes—not by selecting
tasks known to pass—and should include object-to-object relations, variable-size
output construction, masks/regions as first-class values, and compositional
maps over object sets. The same matched population, route-neutral chronology,
complete enumeration, independent zero-survivor checking, and fail-closed
outcomes should remain controls.
