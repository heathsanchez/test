## Promotion law

A challenger can replace a champion only after:

1. universal proof;
2. axiom/restriction audit;
3. negative/falsifying control where applicable;
4. canonical acceptance;
5. measured bytes = proof-checked bytes;
6. paired resource measurement against the protected champion;
7. strict improvement.

A timeout or incomplete search is `UNKNOWN_SEARCH`, not proof of expressivity failure.
