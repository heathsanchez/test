## Source-independent design and protection
- Pin the original archive SHA. Require exact named `SGA_ExE_clustered.cdt` file; metadata header columns start `tsa`, source ORF labels must be parsable from the metadata ORF row and query ORF field. Otherwise STOP/UNKNOWN.
- Seed `20261019`. Select unique query-gene ORFs, **gene-group split**, 70% calibration genes and 30% never-trained target genes. All alleles sharing ORF remain in one partition. Exclude every target gene ORF from **every selected array background** to prevent query-array reciprocal leakage. Across query rows, select one representative allele per ORF based on first source order with all 8 known-panel measurements finite. Never use withheld target candidate scores or missingness to select anything.
- From calibration query genes only, rank each unique array-gene context by finite-score coverage, representative allele by max coverage then smallest column index. Require coverage >= 0.40, choose first 320 by coverage (with canonical ORF tie breaks), seeded-permute, select 8 *known* contexts and 128 *candidate* new contexts; if fewer 136 contexts, STOP.
- Eligibility/pair generation uses **only** eight initially available target-panel scores (and query identities). Greedy disjoint pairs using known-panel maximum absolute difference <= 0.08, 100 pairs maximum, at least 15 or STOP/UNKNOWN. Any target duplicate ORF pairing prohibited. Calibration must have >=100 complete known-panel genes, target >=40. Target candidate outcomes untouched until second CI step.
- For all selectors use same K=31 inverse (distance+0.05) nearest-neighbor model and same observed calibration rows. Novelty claim deliberately NOT asserted: new candidate method is a source-neutral **contrast-mixture** empirical probability of seeing |epsilon difference| >=0.16 among cross-products of independently weighted neighboring calibration rows. Like any active-learning method, it is an explored *heuristic*, not a warranted probabilistic posterior. Missing calibration samples excluded per context; multiply scores by training-only observed availability (shared across point/variance/ridge/uncertainty controls).
- Primary equal-information comparator `knn_point` ranks absolute predicted mean difference, equally multiplied by same observed availability. Additional controls: predictive KNN neighbor-variance **UCB** (uncertainty-aware strong conventional baseline), ridge(alpha=5) point, marginal variance, seeded random (random among 128 same choices). Each picks exactly **one** candidate intervention per pair; missing target experimental outcomes count as non-success for all. No tailoring, retuning or changing threshold in response to ExE outcomes.
- **Separate sealed selection from evaluator**: `predict.py` reads source rows for calibration genes across all columns, but only the eight explicitly permitted measured-panel entries on target genes; target×candidate outcomes are never numerically interpreted in this stage. Saves protocol checks, split identities, all choices and SHA256 of frozen prediction JSON. CI then runs an **independently authored standard-library Decimal evaluator** with original archive after choices are fixed; rechecks row/column gene identity, duplicate leakage, oracle measured bounds, decimal cutoffs, and all outcome flags without importing `predict.py`.
