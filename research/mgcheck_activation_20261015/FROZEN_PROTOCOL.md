## Three matched arms (operations/API/corpus source-identical)
A = Original (untouched) fixed learner: acquire on cast first-local-witness,
persist exact resulting operator, replay on new protected subjects.
B = Finite inventory qualified consequence selection: enumerate all 5 *unchanged*
already-present operators on the SAME 3 historical training source-version pairs.
Choose the operator maximizing number of distinct training source families with
a genuinely verified error->success native witness, using exactly the original
public parse API and native-Go observation predicate. This score is future-obligation
coverage in the predeclared source-family class, not general intent fidelity.
Break ties by LOWER total input count over qualifying families, then the
unchanged prior selector precedence. Never use protected target outcomes for
selection. Retain typed method JSON, exact source/policy digests.
C = Equal-operation/evidence stateless conventional full native differential
enumerator over each protected original source pair using the *same unchanged*
Go learner in acquire mode and all its fixed candidates. The full enumerator
is a competent exhaustive finite-grammar baseline, NOT a separately run
frontier coding LLM, and knows the same training evidence. Economic victory
over fully informed expert/stateless agents cannot be claimed from this alone.

Each arm executes ORIGINAL pinned Go implementation on both source revisions,
not a Python simulator. Required guard: ref SHA, no generated-test counted
as success unless named original-source test actually ran and failed on old,
passed on contributor head; intentionally false assertion fails; no-test check
has NO named observation. Existing unchanged learner enforces these.
