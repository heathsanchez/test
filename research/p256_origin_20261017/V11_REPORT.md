# V11: exact FreeLIP hidden-state inverse exclusion — **10 × 26-bit only**

**Date** 2026-10-17 NZ. **Epistemic status**: `WARRANTED_BOUNDED_LOCAL` with an explicit stdlib-verifiable integer lattice certificate; external CI status separate until qualification. **Historical P-256 G origin**: `UNKNOWN`.

## New result and why it differs from V1/V2

V1/V2 scanned selected starting seed ranges and clock windows; V11 quantifies **all** possible states modulo `2^107−1` with no seed-window assumption, but only one specifically declared output form: 10 consecutive accepted `zrandom(2^26)` low-26-bit limbs, concatenated big- or little-endian and reduced modulo the P-256 field prime. **This is not the known FreeLIP `zrandomb(p)` 11-limb algorithm**, so the original base-point provenance remains unresolved. Avoid inferring that P-256 cannot have been generated by FreeLIP generally.

## Frozen math and complete certificate

Source-derived PRNG: `s_(i+1) = (3^121 mod M)*s_i mod M`, `M=2^107−1`, output `t_i=s_i mod 2^26`. Any raw ten-limb candidate corresponding to the public `Gx` must be exactly `Gx+q*p` for `0<=q<=15`. Check both limb orders, giving **32 cases**.

Define `U=2^26`, `H=floor((M−1)/U)`, `a_i=A^i mod M`, `c_i=(t_i−a_i*t_0)*U^{-1} mod M`, and `s_i=t_i+U*h_i`. Then for `i=1..4`, `h_i ≡ a_i*h_0−c_i (mod M)`. The integer lattice has basis first row `(1,a1,a2,a3,a4)` and remaining rows `M*e_i`. The requested feasible state creates a lattice point in the exact 5D cube `(h_0,h_1+c1,...,h_4+c4)` with `0<=h_i<=H`. Such a point lies in a Euclidean ball of squared radius `5*H²/4` around `(H/2,c1+H/2,...,c4+H/2)`.

SymPy LLL supplies a transformed basis. **The independent verifier checks the exact transformation is unimodular** and the transformed basis equals its declared image, without trusting the LLL implementation or reproducing LLL. It then checks the Gram–Schmidt projections using Python fractions and complete integer coefficient intervals bounded by exact `isqrt`. Among all **32 cases**, just **5 possible final-dimensional coefficients** survive the first projection. **None** survives the second. Therefore no feasible 5-word state exists, and a fortiori no 10-word state exists for these 32 candidates, *within this source grammar*. This is not a failed heuristic search: finite exact exhaustion with a small, separately verifiable certificate.

Control results: six seeded tests (20000/7, 20420/29, 123456789011/3, both directions) recover an actual complete first-output state with exact 10-limb comparison. The P-256 published coordinate has **zero** compatible states in the declared grammar.
