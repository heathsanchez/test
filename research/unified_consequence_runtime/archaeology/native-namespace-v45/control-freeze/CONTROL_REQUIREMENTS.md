# Independent preimplementation control freeze

This pack freezes inputs and acceptance obligations for a small source-preserving native test-namespace extension. It is engineering qualification, not a prospective scientific task. It was prepared against `heathsanchez/test@88aa5090c310d2f75683a019a5bc958cdb3b576e` before reading or importing any V45 implementation. No UDM module was imported, no repository code executed, no new task queried, and no Git mutation made. The fixture writer imports only Python standard-library `ast`, `hashlib`, `json`, and `pathlib`.

`FIXTURE_INDEX.json` contains 30 hand-derived source cases, exact complete baseline/augmented file hashes and modes, and 18 replay/tamper recipes. The bytes under `fixtures/` are the authoritative fixture input; the index does not replace source. `SYNTAX_ONLY_CHECK.json` records parsing synthetic input bytes without import or execution. All fixtures change only `tests/test_native.py`; production/configuration byte maps are equal across each case's baseline and augmented views. A later qualification adapter may put these byte maps into disposable Git repositories, but must retain exact bytes and record every collection/native attempt.

## Minimum core that can be qualified

1. Add a new versioned namespace/assertion derivation and bridge. Preserve original verifier files, original test derivation warrants and earlier UNKNOWN/refusal lineage byte-for-byte. Reuse original configuration parsing, typed source projection, static class inheritance routes, exact collector, independent recollector, licensed plugin/environment identity, required call receipts, and V42/V43 source transport. Do not relabel the old algorithms as having closed the missing declaration binding.
2. The minimum positive wildcard subset is a direct, source-local production module with a statically complete inert namespace. W01 has constants, a plain `Node` class and an uncalled plain helper function. Its package initializer is empty. There are no export protocols, reexports, imported tests, test-like aliases, decorators, metaclasses, opaque initializer calls, dynamic namespace writes, or opaque import loaders. Resolve and bind the complete import route, including package initializers and exact source kinds/modes. If a proposed implementation supports only a smaller subset, state that bound and leave unsupported controls UNKNOWN; never claim W01 is supported unless it actually is.
3. Derive actual wildcard exports from source and configured collection grammar. A claimed list, matching imported value, matching node count, matching module spelling, or absence of a visible `def test_` is insufficient. Reject test/Test-prefixed exports, collection hooks/registration primitives, imported/reexported callables with unresolved origin, fake `__all__`, `__getattr__`, shadowed aliases and ambiguous bindings. A larger recursive export grammar would require separate authority; it is not necessary for this minimum.
4. Bind every original changed required declaration to its exact actual executable object. Preserve declaration source hash and location, qualified origin, inherited class route, code identity and object/callable wrapper identity. Obtain expected code from independently authenticated source under the selected interpreter and actual pytest transformation, or conservatively refuse constructs without an independent comparison. A hash merely supplied by the collector, an `inspect` filename/line lookup, recursively following `__wrapped__`, or stable repeated collection does not close this obligation. B02 and B03 are decisive negatives: their changed assertions fail, their actual wrapper does nothing, and independent collection can reproduce that same no-op.
5. Preserve all actual parameterized nodes and exact collected/selected order, complete imports, licensed plugins, source and runtime identity. Every protected node must have actual setup/call/teardown evidence under original rules. Missing, skipped, xfailed, deselected, suppressed, rebound or deleted assertions cannot promote. Forging every public hash does not remove independent reconstruction/replay.
6. Revalidate the namespace/declaration contract for every source/executable view that may affect test bindings. A production candidate cannot retain stale namespace evidence after changing an imported module or package initializer. Safe ordinary production changes may retain native semantics only when the new bridge independently establishes the same protected assertion authority; otherwise refuse as UNKNOWN. Candidates do not supply authority or edit tests/configuration.
7. Parse authoritative imported Python as Python; retain unrelated malformed Python-looking fixture bytes as data. W02 must still allow real native execution. W03 must not enter native execution under a falsely inert import certificate. W04 must preserve the original runtime `SyntaxError` as FAIL_NATIVE, rather than suppressing the import or interpreting its payload as inert data.

## Optional ordering subset

O01 is optional. The smallest wildcard/assertion extension may leave every attribute/subscript write UNKNOWN and still establish a useful narrow result. If order hooks are supported, authority must identify the actual original `unittest.TestLoader.sortTestMethodsUsing` target, a source-local deterministic effect-free comparator, and its only effect on native ordering. Preserve exact collection, selection and call sequence across producer, independent recollection and execution. The hand-derived O01 unittest method order is `NativeCase::test_b` then `NativeCase::test_a`.

O02 has process entropy and remains outside this deterministic subset. Do not sort away order, normalize it to a set, inject an RNG shim, replace entropy, seed the process, retry until order matches, or introduce an unproved order equivalence. An identically spelled attribute on a shadowed object (O05) grants no capability. Other attribute writes (O03/O07), general namespace writes (O04) and effectful comparators (O06) remain UNKNOWN. This does not authorize the exposed sh diagnostic to execute.

## Required independent verification

Run new controls on exact frozen bytes, retain failures as well as successes, and check outcomes through independently reconstructed source authority plus a separate collector/reexecutor. Tests cannot import the new production parser to generate their own expected exports, source declarations or code bindings. Fixture index/hash checks authenticate input integrity; they do not establish product correctness. A literal expected hash, exported-name list or same-prefix node alone is not sufficient testing of executable assertion binding.

The replay controls are version-independent operation descriptions, not forged executable certificates. Adapt them to the chosen narrow API after the freeze. Preserve their meaning, including resealing all public digest fields in adversarial packets. No fixture currently carries a claimed PASS/FAIL execution receipt.

Existing original test methods listed in SOURCE_EVIDENCE.md should be reused or rerun without rewriting their assertions. Newly frozen acceptance outcomes are hand-derived requirements, not claims that existing source already enforces them. A refusal is appropriate outside declared scope; a refusal of the selected positive core prevents claiming that core is qualified.
